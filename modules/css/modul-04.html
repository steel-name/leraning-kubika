CSS FUNDAMENTAL · MODUL 04

Typography

Pelajari cara mengatur jenis huruf, ukuran, ketebalan, jarak, dan perataan teks agar website nyaman dibaca.

Level: Beginner · Estimasi: 45–60 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami peran typography dalam desain website.
  • Mengatur jenis huruf menggunakan font-family.
  • Mengatur ukuran dan ketebalan teks.
  • Mengatur gaya dan perataan teks.
  • Mengatur jarak antarbaris dan antarhuruf.
  • Menggunakan text decoration dan text transform.
  • Menggunakan Google Fonts dalam website.
Prasyarat: Pahami CSS syntax, selector, serta warna dan background dari modul sebelumnya.

02. Mengenal Typography

Typography adalah pengaturan tampilan huruf dan teks agar informasi mudah dibaca, dipahami, dan terlihat menarik.

Dalam website, typography membantu menentukan karakter visual. Website berita, portofolio, toko online, dan aplikasi belajar dapat menggunakan gaya huruf yang berbeda sesuai kebutuhannya.

Ingat: Typography bukan hanya tentang memilih font yang bagus. Keterbacaan, ukuran, jarak, dan konsistensi juga sangat penting.

03. Font Family

Property font-family digunakan untuk menentukan jenis huruf yang digunakan pada elemen HTML. 

body {
  font-family: Arial, sans-serif;
}

h1 {
  font-family: Georgia, serif;
}

p {
  font-family: "Courier New", monospace;
}

Jenis font umum

JenisContohKarakteristik
SerifGeorgia, Times New RomanMemiliki detail kecil di ujung huruf.
Sans-serifArial, VerdanaTampil sederhana dan bersih.
MonospaceConsolas, Courier NewSetiap karakter memiliki lebar yang sama.
CursiveCursiveMenyerupai tulisan tangan.
Tips: Selalu sediakan font cadangan seperti sans-serif atau serif agar browser tetap memiliki pilihan jika font utama tidak tersedia.

04. Font Size

Property font-size digunakan untuk mengatur ukuran teks. 

h1 {
  font-size: 32px;
}

p {
  font-size: 16px;
}

.small-text {
  font-size: 12px;
}

Satuan ukuran font

Beberapa satuan yang sering digunakan:

SatuanPenjelasan
pxUkuran dalam pixel.
emRelatif terhadap ukuran font elemen induk.
remRelatif terhadap ukuran font elemen root HTML.
%Ukuran relatif terhadap ukuran font elemen induk.

Contoh menggunakan rem

html {
  font-size: 16px;
}

h1 {
  font-size: 2rem;
}

p {
  font-size: 1rem;
}

Jika ukuran font root adalah 16px, maka 2rem setara dengan 32px dan 1rem setara dengan 16px.

Rekomendasi: Gunakan rem untuk membangun ukuran teks yang lebih mudah disesuaikan secara konsisten.

07. Text Align

Property text-align digunakan untuk mengatur perataan teks secara horizontal. 

.left {
  text-align: left;
}

.center {
  text-align: center;
}

.right {
  text-align: right;
}

.justify {
  text-align: justify;
}
Contoh text align

Teks rata kiri.

Teks rata tengah.

Teks rata kanan.

Teks rata kanan dan kiri akan membuat sisi kiri dan kanan paragraf tampak sejajar. Penggunaan perataan ini perlu diperhatikan agar jarak antar kata tetap nyaman dibaca.

Tips: Judul sering menggunakan rata kiri atau tengah, sedangkan paragraf panjang umumnya lebih nyaman dibaca dengan rata kiri.

08. Line Height

Property line-height digunakan untuk mengatur jarak vertikal antarbaris teks. 

p {
  line-height: 1.7;
}
Perbandingan line height

Line height 1.1. Ini merupakan contoh paragraf dengan jarak antarbaris yang cukup rapat sehingga teks terasa padat.

Line height 1.8. Ini merupakan contoh paragraf dengan jarak antarbaris yang lebih renggang sehingga teks terasa lebih lega dan nyaman dibaca.

Rekomendasi: Untuk paragraf panjang, line-height sekitar 1.5 sampai 1.8 sering menjadi titik awal yang baik. Sesuaikan kembali dengan jenis font dan ukuran teks.

09. Text Spacing

CSS menyediakan beberapa property untuk mengatur jarak pada teks.

A. Letter Spacing

Mengatur jarak antarhuruf. 

h1 {
  letter-spacing: 2px;
}

B. Word Spacing

Mengatur jarak antar kata. 

p {
  word-spacing: 5px;
}

11. Menggunakan Google Fonts

Google Fonts menyediakan banyak jenis huruf yang dapat digunakan pada website. Salah satu font yang sering digunakan untuk desain modern adalah Inter.

Langkah 1: Hubungkan Google Fonts

Tambahkan kode berikut di dalam bagian <head> HTML. 

<link rel="preconnect"
  href="https://fonts.googleapis.com">

<link rel="preconnect"
  href="https://fonts.gstatic.com"
  crossorigin>

<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap"
  rel="stylesheet">

Langkah 2: Gunakan font di CSS

body {
  font-family: "Inter", sans-serif;
}

h1 {
  font-weight: 800;
}

p {
  font-weight: 400;
}
Catatan: Google Fonts memerlukan koneksi internet saat font diunduh oleh browser. Jika website harus bekerja secara offline, gunakan font lokal atau font sistem sebagai cadangan.
