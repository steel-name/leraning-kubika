CSS Learning Path • Module 10

Transitions, Transforms & Animations

Pelajari cara membuat website lebih hidup dengan efek transisi, perubahan bentuk, dan animasi menggunakan CSS.

Beginner–Intermediate 75–100 Menit Teori + Praktik Mini Project
01 • Pengenalan

Mengapa Website Membutuhkan Animasi?

Website bukan hanya tentang tampilan yang bagus. Interaksi visual juga membantu pengguna memahami respons dari sebuah elemen.

Contohnya, ketika pengguna mengarahkan kursor ke tombol, tombol berubah warna atau sedikit terangkat. Perubahan tersebut memberikan tanda bahwa tombol dapat digunakan.

Tiga Konsep Utama

Konsep Fungsi Contoh
Transition Menghaluskan perubahan nilai CSS dari satu kondisi ke kondisi lain. Warna tombol berubah perlahan.
Transform Mengubah posisi, ukuran, rotasi, atau kemiringan elemen. Kartu bergerak ke atas saat hover.
Animation Membuat rangkaian perubahan CSS menggunakan keyframes. Ikon berputar terus-menerus.

Bagaimana Ketiganya Bekerja Bersama?

.card {
  transition: transform .3s ease;
}

.card:hover {
  transform: translateY(-8px);
}

Pada contoh tersebut, transform mengatur perubahan posisi kartu, sedangkan transition membuat perubahan posisi berlangsung secara halus.

Kesimpulan: Transition menghaluskan perubahan, Transform mengubah tampilan visual, dan Animation menjalankan rangkaian perubahan yang didefinisikan menggunakan keyframes.
02 • Transitions

Mengenal CSS Transition

Transition digunakan untuk membuat perubahan properti CSS berlangsung secara bertahap, bukan langsung berubah secara mendadak.

Contoh tanpa Transition

.button {
  background: blue;
}

.button:hover {
  background: red;
}

Warna tombol berubah langsung ketika pointer diarahkan ke tombol.

Contoh menggunakan Transition

.button {
  background: blue;
  transition: background .3s ease;
}

.button:hover {
  background: red;
}

Sekarang perubahan warna berlangsung selama 0,3 detik secara halus.

Demo Langsung

Arahkan kursor

Arahkan pointer ke kotak untuk melihat efek transition.

Properti Transition

transition: property duration timing-function delay;
Bagian Fungsi Contoh
property Properti CSS yang ingin dianimasikan. background, transform
duration Lama perubahan berlangsung. .3s, 500ms
timing-function Mengatur pola kecepatan perubahan. ease, linear
delay Waktu tunggu sebelum perubahan dimulai. .2s

Menggunakan Beberapa Properti

.card {
  transition:
    transform .3s ease,
    box-shadow .3s ease,
    background .3s ease;
}

.card:hover {
  transform: translateY(-5px);
  box-shadow: 0 10px 20px #0002;
}
Kesalahan umum: Transition biasanya ditulis pada kondisi awal elemen, bukan hanya pada :hover. Dengan begitu, perubahan saat pointer masuk maupun keluar bisa berlangsung halus.
03 • Timing & Delay

Mengatur Kecepatan Transisi

Timing function menentukan bagaimana kecepatan perubahan berlangsung sepanjang durasi transition.

Nilai Karakteristik
linear Kecepatan tetap dari awal sampai akhir.
ease Mulai perlahan, lebih cepat di tengah, lalu melambat.
ease-in Mulai perlahan lalu semakin cepat.
ease-out Mulai cepat lalu melambat.
ease-in-out Mulai dan berakhir secara perlahan.
cubic-bezier() Mengatur kurva kecepatan secara khusus.

Contoh Penggunaan

.box {
  transition: transform .5s ease-in-out .2s;
}

.box:hover {
  transform: translateX(30px);
}

Elemen menunggu 0,2 detik, kemudian bergerak selama 0,5 detik.

Perbedaan Timing Function

Arahkan pointer ke setiap tombol untuk membandingkan efeknya.

Linear
Ease
Ease-in
Ease-out
Durasi dan timing function adalah dua hal berbeda. Duration mengatur berapa lama perubahan berlangsung, sedangkan timing function mengatur pola kecepatannya.
04 • Transforms

Mengenal CSS Transform

Transform memungkinkan kita mengubah bentuk atau posisi visual sebuah elemen tanpa mengubah alur normal layout dokumen.

1. translate()

Digunakan untuk memindahkan elemen pada sumbu X dan Y.

.box {
  transform: translate(20px, 10px);
}

Elemen bergerak 20px ke kanan dan 10px ke bawah.

2. scale()

Digunakan untuk memperbesar atau memperkecil elemen.

.box {
  transform: scale(1.2);
}

Elemen menjadi 1,2 kali ukuran awalnya.

3. rotate()

Digunakan untuk memutar elemen.

.box {
  transform: rotate(45deg);
}

Nilai positif memutar searah jarum jam, sedangkan nilai negatif memutar berlawanan arah jarum jam.

4. skew()

Digunakan untuk memiringkan elemen.

.box {
  transform: skew(10deg, 5deg);
}

05 • Transform Origin

Mengatur Titik Transformasi

Secara default, transform dilakukan dari titik tengah elemen. Kita dapat mengubah titik tersebut menggunakan transform-origin. 

.box {
  transform-origin: top left;
  transform: rotate(15deg);
}

Beberapa Nilai Transform Origin

  • center: titik tengah.
  • top left: sudut kiri atas.
  • top right: sudut kanan atas.
  • bottom center: bagian tengah bawah.
  • 50% 50%: titik tengah dalam bentuk persentase.

Contoh Penggunaan

.card {
  transform-origin: bottom right;
}

.card:hover {
  transform: rotate(5deg);
}

06 • Keyframes

Membuat Animasi dengan @keyframes

Keyframes adalah aturan CSS yang mendefinisikan tahapan perubahan dalam sebuah animasi.

Kita dapat menentukan kondisi awal, kondisi tengah, dan kondisi akhir. 

@keyframes moveBox {
  from {
    transform: translateX(0);
  }

  to {
    transform: translateX(100px);
  }
}

Animasi tersebut memindahkan elemen dari posisi awal ke kanan sejauh 100px.

Menggunakan Persentase

@keyframes colorChange {
  0% {
    background: blue;
  }

  50% {
    background: cyan;
  }

  100% {
    background: purple;
  }
}

Persentase menunjukkan posisi tahapan animasi dari awal hingga akhir.

Contoh Animasi Bergerak

@keyframes bounce {
  0%, 100% {
    transform: translateY(0);
  }

  50% {
    transform: translateY(-20px);
  }
}

.ball {
  animation: bounce 1s ease-in-out infinite;
}
Perbedaan penting: @keyframes mendefinisikan gerakan, sedangkan properti animation menentukan bagaimana gerakan itu dijalankan.
07 • Animation Properties

Mengatur Animation

CSS memiliki beberapa properti untuk mengatur jalannya animasi. 

animation: name duration timing-function
           delay iteration-count direction
           fill-mode play-state;
Properti Fungsi Contoh
animation-name Nama keyframes. bounce
animation-duration Lama satu siklus animasi. 2s
animation-timing-function Pola kecepatan. ease-in-out
animation-delay Waktu tunggu sebelum animasi. 1s
animation-iteration-count Jumlah pengulangan. 3, infinite
animation-direction Arah animasi. normal, reverse, alternate
animation-fill-mode Menentukan gaya sebelum atau sesudah animasi. forwards, backwards
animation-play-state Menjalankan atau menjeda animasi. running, paused

Contoh Lengkap

.box {
  animation-name: bounce;
  animation-duration: 2s;
  animation-timing-function: ease-in-out;
  animation-delay: .5s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

Versi singkat:

.box {
  animation: bounce 2s ease-in-out .5s infinite alternate;
}

Apa Itu Animation Fill Mode?

Fill mode mengatur apakah gaya dari animasi tetap diterapkan sebelum atau sesudah animasi berlangsung.

  • none: tidak mempertahankan gaya keyframes.
  • forwards: mempertahankan kondisi akhir animasi.
  • backwards: menerapkan kondisi awal selama delay.
  • both: menggabungkan forwards dan backwards.

Mengenal Animation Direction

  • normal: berjalan dari awal ke akhir.
  • reverse: berjalan dari akhir ke awal.
  • alternate: bergantian maju dan mundur.
  • alternate-reverse: bergantian dengan arah awal terbalik.
Hati-hati menggunakan infinite. Animasi tanpa henti bisa mengganggu pengguna jika terlalu banyak atau terlalu mencolok.
08 • Hover & Interaction

Membuat Interaksi yang Menarik

Hover adalah kondisi ketika pointer diarahkan ke sebuah elemen. Kita bisa menggabungkan hover dengan transition dan transform untuk membuat interaksi yang lebih responsif.

Contoh Tombol Interaktif

.button {
  background: #2563eb;
  color: white;
  transition:
    transform .2s ease,
    box-shadow .2s ease;
}

.button:hover {
  transform: translateY(-3px);
  box-shadow: 0 8px 18px #2563eb40;
}

.button:active {
  transform: scale(.97);
}

Efek Tambahan

/* Memudarkan elemen */
.card:hover {
  opacity: .8;
}

/* Mengubah kecerahan */
.image:hover {
  filter: brightness(1.1);
}

/* Mengubah warna */
.link:hover {
  color: #2563eb;
}
Jangan mengandalkan hover saja untuk informasi penting. Pengguna smartphone umumnya menggunakan layar sentuh, bukan pointer.
09 • Performance

Membuat Animasi yang Ringan

Animasi yang terlalu banyak atau menggunakan properti yang kurang tepat bisa membuat website terasa lambat.

Properti yang Umumnya Baik untuk Animasi

  • transform: memindahkan, memutar, atau mengubah ukuran secara visual.
  • opacity: mengubah tingkat transparansi.

Contoh Animasi Sederhana

.card {
  transition:
    transform .25s ease,
    opacity .25s ease;
}

.card:hover {
  transform: translateY(-5px);
  opacity: .9;
}

Animasi pada properti seperti width, height, top, dan left bisa memicu perhitungan ulang layout atau pengecatan ulang. Gunakan dengan pertimbangan.

Hindari Hal Berikut

  • Animasi terlalu banyak dalam satu halaman.
  • Durasi terlalu panjang untuk interaksi sederhana.
  • Menggerakkan banyak elemen besar secara bersamaan.
  • Menambahkan efek hanya karena terlihat keren tanpa tujuan.
Prinsipnya: animasi harus membantu pengalaman pengguna, bukan mengganggunya.
10 • Accessibility

Memperhatikan Kenyamanan Pengguna

Sebagian pengguna lebih nyaman jika gerakan pada website dikurangi. CSS menyediakan media query prefers-reduced-motion untuk mendeteksi preferensi tersebut. 

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}

Aturan tersebut mengurangi durasi animasi dan transisi ketika pengguna mengaktifkan preferensi pengurangan gerakan pada perangkatnya.

Prinsip Animasi yang Nyaman

  • Hindari kedipan cepat dan berulang.
  • Jangan membuat animasi yang mengganggu pembacaan.
  • Berikan kontrol jeda untuk animasi yang berjalan lama jika diperlukan.
  • Pastikan informasi tetap tersedia walaupun animasi tidak dijalankan.
  • Pastikan tombol dan elemen interaktif tetap mudah digunakan.
Accessibility bukan sekadar tambahan. Website yang baik harus tetap nyaman digunakan oleh berbagai pengguna.
