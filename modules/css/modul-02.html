CSS FUNDAMENTAL · MODUL 02

CSS Syntax & Selectors

Pelajari cara menulis aturan CSS dan memilih elemen HTML yang ingin kamu ubah tampilannya.

Level: Beginner · Estimasi: 45–60 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami struktur dasar penulisan CSS.
  • Menggunakan element selector.
  • Membedakan class selector dan ID selector.
  • Menggunakan grouping selector.
  • Menggabungkan beberapa selector sederhana.
  • Menerapkan selector pada halaman HTML.
Prasyarat: Kamu sudah memahami struktur HTML dan cara menghubungkan file CSS eksternal dari Modul 01.

02. Memahami CSS Syntax

CSS memiliki aturan penulisan yang disebut CSS syntax. Aturan ini menentukan elemen mana yang akan diberi gaya dan bagaimana tampilannya diubah. 

p {
  color: blue;
  font-size: 18px;
}

Struktur tersebut terdiri dari tiga bagian utama:

  • Selector: menentukan elemen HTML yang dipilih.
  • Property: menentukan bagian tampilan yang diubah.
  • Value: menentukan nilai dari property.
BagianContohFungsi
SelectorpMemilih semua elemen paragraf.
PropertycolorMengatur warna teks.
ValueblueMenentukan warna biru.
Perhatikan: Setiap deklarasi CSS diakhiri dengan titik koma (;). Property dan value dipisahkan dengan tanda titik dua (:).

Contoh lainnya

h1 {
  color: navy;
  background-color: lightblue;
  text-align: center;
}

Artinya, semua elemen h1 akan memiliki teks berwarna navy, latar belakang biru muda, dan posisi teks di tengah.

03. Element Selector

Element selector digunakan untuk memilih elemen HTML berdasarkan nama tag-nya. 

p {
  color: gray;
}

h1 {
  color: blue;
}

button {
  background-color: black;
  color: white;
}
Contoh hasil

Judul Website

Ini adalah paragraf yang tampil berwarna abu-abu.

Jika kamu menggunakan selector p, semua elemen paragraf pada halaman akan terkena aturan tersebut.

Kapan digunakan? Gunakan element selector ketika kamu ingin memberikan gaya dasar yang sama kepada seluruh elemen dengan tag tertentu.

04. Class Selector

Class selector digunakan untuk memilih elemen berdasarkan atribut class pada HTML. Penulisannya di CSS diawali dengan tanda titik (.).

Contoh HTML

<h1 class="judul">Selamat Datang</h1>

<p class="deskripsi">
  Belajar CSS bersama DevLearn.
</p>

<p class="deskripsi">
  Belajar membuat website dari dasar.
</p>

Contoh CSS

.judul {
  color: blue;
  text-align: center;
}

.deskripsi {
  color: gray;
  font-size: 16px;
}
Ingat: Satu class dapat digunakan oleh banyak elemen HTML. Bahkan satu elemen bisa memiliki beberapa class.

Contoh beberapa class

<p class="teks-biru tebal">
  Belajar CSS itu menyenangkan.
</p>
.teks-biru {
  color: blue;
}

.tebal {
  font-weight: bold;
}

05. ID Selector

ID selector digunakan untuk memilih elemen berdasarkan atribut id. Penulisannya diawali dengan tanda pagar (#). 

<h1 id="judul-utama">
  Website Pertamaku
</h1>
#judul-utama {
  color: darkblue;
  text-align: center;
  font-size: 32px;
}
Perbedaan penting: ID sebaiknya unik dalam satu halaman HTML. Jangan menggunakan ID yang sama untuk banyak elemen.

Class vs ID

ClassID
Diawali titik (.).Diawali pagar (#).
Dapat digunakan berulang kali.Sebaiknya unik dalam satu halaman.
Cocok untuk gaya yang digunakan berulang.Cocok untuk identitas satu elemen tertentu.

06. Grouping Selector

Grouping selector memungkinkan kita memberikan aturan CSS yang sama kepada beberapa selector sekaligus. Setiap selector dipisahkan menggunakan koma. 

h1, h2, p {
  font-family: Arial, sans-serif;
  color: #334155;
}

Contoh tersebut membuat semua elemen h1, h2, dan p menggunakan jenis font dan warna yang sama.

Manfaat: Kode menjadi lebih ringkas dan tidak perlu menulis aturan yang sama berkali-kali.

07. Selector Kombinasi Dasar

Selain memilih elemen secara langsung, kita juga bisa memilih elemen berdasarkan hubungannya dengan elemen lain.

Descendant Selector

Menggunakan spasi untuk memilih elemen yang berada di dalam elemen lainnya, baik secara langsung maupun bertingkat. 

.card p {
  color: gray;
}

Artinya, semua paragraf yang berada di dalam elemen dengan class card akan berwarna abu-abu.

Child Selector

Menggunakan tanda lebih besar (>) untuk memilih elemen yang merupakan anak langsung dari elemen tertentu. 

.menu > a {
  color: navy;
}

Aturan ini hanya memilih elemen a yang menjadi anak langsung dari elemen dengan class menu.

Tips belajar: Kuasai element, class, dan ID terlebih dahulu. Selector kombinasi akan terasa lebih mudah setelah kamu terbiasa membaca struktur HTML.

08. Latihan Praktik

Sekarang waktunya mencoba sendiri. Buat dua file berikut: 

latihan-selector/
├── index.html
└── style.css

File index.html

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
    content="width=device-width, initial-scale=1.0">
  <title>Latihan CSS Selector</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <h1 id="judul">Belajar CSS Selector</h1>

  <p class="deskripsi">
    Saya sedang belajar CSS dari dasar.
  </p>

  <div class="card">
    <h2>Materi Pertama</h2>
    <p>Belajar mengenal selector CSS.</p>
  </div>

  <div class="card">
    <h2>Materi Kedua</h2>
    <p>Belajar menerapkan selector.</p>
  </div>

</body>
</html>

File style.css

/* Selector ID */
#judul {
  color: navy;
  text-align: center;
}

/* Selector Class */
.deskripsi {
  color: gray;
  text-align: center;
}

/* Element Selector */
h2 {
  color: blue;
}

/* Grouping Selector */
h1, h2 {
  font-family: Arial, sans-serif;
}

/* Descendant Selector */
.card p {
  color: green;
}

Tugas eksplorasi

  1. Ubah warna judul menjadi merah.
  2. Ubah semua paragraf deskripsi menjadi biru.
  3. Buat class baru bernama highlight.
  4. Terapkan class tersebut pada salah satu paragraf.
  5. Coba ubah tampilan elemen menggunakan ID dan class.
Target: Kamu harus bisa menjelaskan mengapa suatu elemen berubah warna setelah selector tertentu diterapkan.

  • Menggunakan minimal tiga class selector.
  • Menggunakan minimal satu grouping selector.
  • Menggunakan minimal satu descendant selector.
  • Memisahkan HTML dan CSS ke dalam dua file.
