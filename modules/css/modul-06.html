CSS FUNDAMENTAL · MODUL 06

Display & Position

Pelajari bagaimana elemen HTML ditampilkan dan bagaimana mengatur posisi elemen agar halaman website tersusun rapi.

Level: Beginner · Estimasi: 45–60 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami fungsi property display.
  • Membedakan block, inline, dan inline-block.
  • Memahami fungsi display: none.
  • Memahami lima jenis position pada CSS.
  • Menggunakan top, right, bottom, dan left.
  • Memahami stacking order melalui z-index.
  • Mengatur posisi elemen dalam halaman website.
Prasyarat: Pahami HTML dasar dan CSS Box Model dari Modul 05.

02. Mengenal Display

Property display digunakan untuk menentukan bagaimana sebuah elemen HTML ditampilkan dalam halaman.

Setiap elemen HTML memiliki perilaku tampilan default. Contohnya, elemen div biasanya ditampilkan sebagai block, sedangkan span biasanya ditampilkan sebagai inline.

Beberapa nilai display yang sering digunakan:

  • block
  • inline
  • inline-block
  • none
  • flex
  • grid
Pada modul ini kita fokus pada block, inline, inline-block, dan none. Flexbox dan Grid akan dipelajari lebih mendalam pada modul berikutnya.

03. Display Block

Elemen dengan display: block biasanya mengambil seluruh lebar yang tersedia pada barisnya.

Karakteristiknya:

  • Dimulai pada baris baru.
  • Biasanya memenuhi lebar container.
  • Dapat diatur width dan height.
  • Dapat diberikan margin dan padding.

Contoh elemen block: div, p, h1, section, dan article.

.box {
  display: block;
  width: 200px;
  padding: 12px;
  background: #bfdbfe;
}

04. Display Inline

Elemen inline hanya menggunakan ruang sesuai kebutuhan kontennya dan tetap berada dalam alur teks yang sama.

Karakteristiknya:

  • Tidak memulai baris baru.
  • Lebarnya mengikuti konten.
  • Width dan height tidak berlaku seperti pada elemen block.
  • Padding dan border dapat diterapkan, tetapi tidak mengubah alur baris seperti block.

Contoh elemen inline: span, a, strong, dan em.

.text {
  display: inline;
  background: #bbf7d0;
}

Elemen inline tidak menerima width dan height seperti block. Jika kamu ingin elemen tetap sejajar tetapi dapat diatur ukurannya, gunakan inline-block.

05. Display Inline-block

Inline-block menggabungkan perilaku inline dan block. Elemen tetap dapat berjajar dalam satu baris, tetapi width dan height bisa diatur. 

.box {
  display: inline-block;
  width: 120px;
  height: 70px;
  padding: 12px;
}

07. Mengenal Position

Property position digunakan untuk mengatur bagaimana sebuah elemen ditempatkan dalam halaman.

CSS menyediakan lima nilai position yang perlu kamu pahami:

  • static
  • relative
  • absolute
  • fixed
  • sticky

Untuk mengatur letaknya, kita dapat menggunakan: top, right, bottom, dan left.

Nilai top, right, bottom, dan left tidak memindahkan elemen ketika position masih static.

08. Position Static

Static adalah posisi default setiap elemen HTML. Elemen ditampilkan mengikuti alur normal dokumen. 

.box {
  position: static;
}
Contoh static
Static 1
Static 2
Static 3

Elemen tetap berada pada urutan normal halaman. Property top, right, bottom, dan left tidak berpengaruh pada elemen static.

09. Position Relative

Relative memungkinkan elemen digeser dari posisi awalnya menggunakan top, right, bottom, atau left. 

.box {
  position: relative;
  top: 20px;
  left: 25px;
}
Contoh relative
Normal
Relative

Elemen relative bergeser dari tempat awalnya, tetapi ruang awalnya tetap dipertahankan dalam layout.

Relative juga sering digunakan pada parent agar menjadi acuan posisi untuk elemen absolute di dalamnya.

10. Position Absolute

Absolute membuat elemen keluar dari alur normal dokumen. Elemen biasanya diposisikan berdasarkan ancestor terdekat yang memiliki position selain static. 

.parent {
  position: relative;
}

.child {
  position: absolute;
  right: 12px;
  bottom: 12px;
}
Contoh absolute
Parent: position relative
Absolute

Pada contoh tersebut, elemen absolute berada di kanan bawah parent karena parent menggunakan position relative.

Contoh penggunaan nyata

  • Badge diskon pada product card.
  • Ikon pada sudut gambar.
  • Tombol close pada modal.
  • Label pada thumbnail.
Jika tidak ada ancestor yang diposisikan, elemen absolute akan menggunakan containing block lain, umumnya initial containing block. Karena itu, perhatikan struktur parent dan child saat menggunakannya.

11. Position Fixed

Fixed membuat elemen tetap berada pada posisi tertentu relatif terhadap viewport, meskipun halaman di-scroll. 

.floating-button {
  position: fixed;
  right: 20px;
  bottom: 20px;
}

Contoh penggunaan fixed:

  • Tombol kembali ke atas.
  • Tombol chat yang selalu terlihat.
  • Floating action button.
  • Elemen navigasi yang menempel pada layar.

12. Position Sticky

Sticky menggabungkan perilaku relative dan fixed. Elemen awalnya mengikuti alur normal, kemudian menempel pada posisi tertentu saat area scroll mencapainya. 

.navbar {
  position: sticky;
  top: 0;
}

Sticky membutuhkan nilai batas seperti top: 0 agar perilaku menempelnya dapat terlihat. Perhatikan juga ancestor yang memiliki overflow karena dapat memengaruhi area scroll sticky.

13. Mengenal Z-index

Z-index digunakan untuk mengatur urutan tumpukan elemen. Semakin besar nilai z-index, semakin tinggi posisi elemen dalam stacking order pada konteks yang sama. 

.box-one {
  position: absolute;
  z-index: 1;
}

.box-two {
  position: absolute;
  z-index: 2;
}
Contoh z-index
Z-index 1
Z-index 2
Z-index 3
Z-index tidak selalu bisa dibandingkan langsung antar elemen jika berada pada stacking context yang berbeda. Jadi, angka besar tidak otomatis membuat elemen selalu tampil paling depan.
