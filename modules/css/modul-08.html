CSS Learning Path • Module 08

CSS Grid

Pelajari cara membuat layout website menggunakan sistem baris dan kolom. Bangun tampilan yang rapi, fleksibel, dan responsif.

Beginner–Intermediate Estimasi 60–90 menit Praktik + Challenge
01 • Pengenalan

Apa Itu CSS Grid?

CSS Grid adalah sistem layout pada CSS yang memungkinkan kita menyusun elemen website dalam bentuk baris (rows) dan kolom (columns).

Dengan Grid, kita bisa mengatur posisi elemen secara lebih terstruktur. Contohnya untuk membuat dashboard, galeri foto, halaman portfolio, dan layout website.

Bagaimana Grid Bekerja?

  • Grid Container: elemen induk yang menggunakan display: grid;.
  • Grid Items: elemen anak langsung di dalam Grid Container.
  • Grid Lines: garis pembatas kolom dan baris.
  • Grid Tracks: ruang berupa kolom atau baris.
  • Grid Cell: satu sel yang terbentuk dari pertemuan satu baris dan satu kolom.

Perbedaan Flexbox dan Grid

FlexboxGrid
Utamanya mengatur satu dimensi.Mengatur dua dimensi sekaligus.
Berfokus pada satu baris atau kolom.Berfokus pada baris dan kolom.
Cocok untuk navbar dan susunan tombol.Cocok untuk galeri dan layout halaman.
Ingat: Flexbox dan Grid bukan untuk saling menggantikan. Keduanya bisa digunakan bersama dalam satu website.
02 • Grid Container

Membuat Grid Pertama

Untuk mengaktifkan CSS Grid, gunakan display: grid; pada elemen induk (parent). Elemen anak langsungnya akan menjadi Grid Items.

.container {
  display: grid;
}

Contoh HTML:

<div class="container">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

Jika hanya menggunakan display: grid;, browser akan membuat satu kolom eksplisit secara default, sedangkan item berikutnya ditempatkan pada baris baru. Kita bisa mengatur struktur kolomnya sendiri.

Elemen yang berada di dalam Grid Container tetapi bukan anak langsung tidak otomatis menjadi Grid Item. Grid bekerja pada anak langsungnya.
03 • Columns & Rows

Mengatur Kolom dan Baris

Properti grid-template-columns digunakan untuk menentukan jumlah dan ukuran kolom.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

Kode tersebut membuat tiga kolom dengan ukuran yang sama.

Kolom 2
Kolom 3

Kita juga bisa menggunakan ukuran berbeda:

.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
}

Kolom pertama memiliki lebar 200px, sedangkan dua kolom lainnya membagi sisa ruang yang tersedia secara sama.

Mengatur Baris

Gunakan grid-template-rows untuk menentukan ukuran baris.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 100px 200px;
}
Urutan nilai pada columns dan rows menentukan ukuran track dari kiri ke kanan dan dari atas ke bawah. Jika item lebih banyak daripada track yang ditentukan, browser dapat membuat baris tambahan secara otomatis.
04 • Unit Grid

Mengenal fr, repeat(), dan minmax()

1. Unit fr

fr berarti fraction atau bagian dari ruang yang tersedia pada Grid Container. Unit ini membagi ruang fleksibel setelah ukuran tetap dan kebutuhan lainnya diperhitungkan.

grid-template-columns: 2fr 1fr;

Kolom pertama mendapatkan dua bagian, sedangkan kolom kedua mendapatkan satu bagian dari ruang fleksibel yang tersedia.

2fr
1fr

2. Fungsi repeat()

Digunakan untuk mengulang pola ukuran kolom atau baris agar penulisan CSS lebih ringkas.

grid-template-columns: repeat(3, 1fr);

/* Sama dengan: */
grid-template-columns: 1fr 1fr 1fr;

3. Fungsi minmax()

Digunakan untuk menentukan ukuran minimum dan maksimum sebuah track.

grid-template-columns:
  repeat(3, minmax(150px, 1fr));

Artinya, setiap kolom memiliki ukuran minimum 150px dan dapat berkembang hingga mengambil bagian ruang fleksibel yang tersedia.

Perhatikan: Jika container terlalu sempit, tiga kolom dengan minimum 150px belum tentu muat. Gunakan pola responsif seperti auto-fit dan minmax() untuk menyesuaikan jumlah kolom.
05 • Jarak Grid

Mengatur Jarak dengan Gap

Properti gap digunakan untuk memberikan jarak antar kolom dan baris.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Jika ingin mengatur jarak secara terpisah:

.container {
  row-gap: 20px;
  column-gap: 12px;
}
  • row-gap: jarak antarbaris.
  • column-gap: jarak antarkolom.
  • gap: cara singkat untuk mengatur keduanya.
Gap berbeda dengan margin. Gap mengatur jarak antar-track di dalam container, sedangkan margin mengatur ruang di luar elemen.
06 • Grid Placement

Mengatur Posisi Item

Kita bisa menentukan sebuah item menempati kolom atau baris tertentu menggunakan grid-column dan grid-row.

.item-1 {
  grid-column: 1 / 3;
}

Artinya, item dimulai dari garis kolom 1 dan berakhir pada garis kolom 3. Jadi item tersebut menempati dua track kolom.

Kita juga bisa menggunakan span untuk menyatakan jumlah track yang ditempati.

.item-1 {
  grid-column: span 2;
  grid-row: span 2;
}

07 • Grid Areas

Menggunakan Grid Template Areas

grid-template-areas memungkinkan kita menyusun layout menggunakan nama area. Ini sangat membantu ketika membuat struktur halaman website.

.container {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-template-rows: 60px 180px 60px;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  gap: 10px;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }
HEADER
SIDEBAR
CONTENT
FOOTER
Nama area harus membentuk susunan yang valid dan berbentuk persegi panjang. Area yang tidak digunakan bisa ditulis menggunakan tanda titik (.).

Contoh area kosong:

grid-template-areas:
  "header header"
  "sidebar content"
  ". footer";
08 • Responsive Grid

Membuat Grid Responsif

Website yang baik harus bisa menyesuaikan tampilan pada desktop, tablet, dan smartphone.

Grid memiliki auto-fit dan auto-fill yang bisa digunakan bersama minmax().

.gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(180px, 1fr));
  gap: 16px;
}

Browser akan menyesuaikan jumlah kolom berdasarkan ruang yang tersedia. Setiap kolom memiliki ukuran minimum 180px dan dapat melebar.

Perbedaan auto-fit dan auto-fill

auto-fitauto-fill
Track kosong yang tidak terpakai akan diciutkan sehingga item yang ada dapat melebar.Mempertahankan track kosong yang masih muat di dalam container.
Cocok untuk galeri yang ingin mengisi ruang kosong.Berguna ketika ingin mempertahankan pola track.
Tips: Untuk galeri portfolio, auto-fit dan minmax() adalah kombinasi yang praktis.

Responsive dengan Media Query

Selain menggunakan auto-fit, kita juga bisa mengubah struktur Grid berdasarkan ukuran layar.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

@media (max-width: 768px) {
  .gallery {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 480px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}
09 • Alignment

Mengatur Posisi Isi Grid

Grid menyediakan properti untuk mengatur posisi item di dalam area Grid dan posisi keseluruhan track.

PropertiFungsi
align-itemsMengatur posisi item pada sumbu block, umumnya vertikal.
justify-itemsMengatur posisi item pada sumbu inline, umumnya horizontal.
place-itemsShorthand untuk align-items dan justify-items.
align-contentMengatur posisi keseluruhan track pada sumbu block.
justify-contentMengatur posisi keseluruhan track pada sumbu inline.
place-contentShorthand untuk align-content dan justify-content.
.container {
  display: grid;
  place-items: center;
}

Kode tersebut membuat isi setiap area Grid berada di tengah secara horizontal dan vertikal.
