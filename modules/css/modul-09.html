Responsive Design & Media Queries

01 • Pengenalan

Apa Itu Responsive Design?

Responsive Design adalah pendekatan dalam membuat website agar tampilan dan susunan elemennya dapat menyesuaikan ukuran layar perangkat yang digunakan.

Website bisa dibuka melalui laptop, tablet, maupun smartphone. Namun, ukuran layar dan cara pengguna berinteraksi dengan perangkat tersebut berbeda.

Tujuan Responsive Design

  • Konten mudah dibaca pada layar kecil.
  • Pengguna tidak perlu menggeser layar ke samping untuk membaca halaman biasa.
  • Navigasi tetap mudah digunakan.
  • Gambar dan komponen tidak keluar dari batas layar.
  • Pengalaman pengguna tetap nyaman di berbagai perangkat.
Ingat: Responsive Design bukan sekadar mengecilkan ukuran website. Kita juga perlu menyesuaikan susunan konten, navigasi, jarak, dan interaksi.
02 • Viewport

Mengenal Viewport

Viewport adalah area halaman web yang terlihat oleh pengguna pada layar perangkat.

Dalam HTML, kita perlu menambahkan meta viewport agar browser mobile menggunakan lebar viewport sesuai lebar perangkat. 

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Penjelasan:

  • width=device-width: lebar viewport mengikuti lebar perangkat.
  • initial-scale=1.0: tingkat zoom awal ditetapkan pada skala normal.
Jangan dilewatkan! Tanpa meta viewport, halaman pada perangkat mobile bisa dirender seolah-olah memiliki lebar desktop sehingga layout responsive tidak bekerja sebagaimana mestinya.
03 • Pendekatan

Mengenal Mobile First

Mobile First adalah pendekatan desain dan pengembangan yang memulai pembuatan tampilan dari layar kecil, kemudian menambahkan penyesuaian untuk layar yang lebih besar.

Contohnya, pada smartphone kita menampilkan satu kolom, lalu pada desktop kita mengubahnya menjadi tiga kolom.

Contoh CSS Mobile First

/* Tampilan dasar untuk layar kecil */
.container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet dan layar lebih besar */
@media (min-width: 768px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .container {
    grid-template-columns: repeat(3, 1fr);
  }
}
Mobile First bukan berarti website hanya dibuat untuk smartphone. Kita memulai dari layout sederhana, lalu meningkatkannya sesuai ruang yang tersedia.

Mobile First vs Desktop First

Mobile First Desktop First
CSS dasar untuk layar kecil. CSS dasar untuk layar besar.
Menggunakan min-width untuk memperluas layout. Umumnya menggunakan max-width untuk menyederhanakan layout.
Cocok untuk proyek yang memprioritaskan pengalaman mobile. Bisa digunakan ketika desain awal berpusat pada desktop.
04 • Media Queries

Apa Itu Media Queries?

Media Queries adalah fitur CSS yang memungkinkan kita menerapkan aturan tertentu berdasarkan kondisi perangkat atau viewport, seperti lebar layar, tinggi layar, dan orientasi. 

@media (max-width: 600px) {
  body {
    background: lightblue;
  }
}

Artinya, warna latar belakang akan berubah menjadi biru muda ketika lebar viewport 600px atau kurang.

Contoh penggunaan lainnya

/* Jika layar maksimal 600px */
@media (max-width: 600px) {
  .title {
    font-size: 24px;
  }
}

/* Jika layar minimal 768px */
@media (min-width: 768px) {
  .title {
    font-size: 36px;
  }
}

Operator yang sering digunakan

Sintaks Makna
max-width: 600px Lebar viewport 600px atau lebih kecil.
min-width: 768px Lebar viewport 768px atau lebih besar.
orientation: portrait Orientasi viewport lebih tinggi daripada lebar.
orientation: landscape Orientasi viewport lebih lebar daripada tinggi.
Media Queries tidak hanya digunakan untuk ukuran layar. Kita juga dapat menggunakannya untuk mendeteksi preferensi pengguna, seperti prefers-reduced-motion.
05 • Breakpoints

Menentukan Breakpoints

Breakpoint adalah titik ukuran viewport ketika kita mengubah atau menyesuaikan layout website.

Contoh pembagian ukuran layar:

Ukuran viewport Contoh target
Di bawah 600px Smartphone
600px–767px Smartphone besar atau tablet kecil
768px–1023px Tablet
1024px ke atas Laptop dan desktop
Ukuran di atas hanya contoh, bukan standar wajib. Breakpoint terbaik ditentukan berdasarkan kapan konten atau layout mulai terlihat tidak nyaman.

Contoh beberapa breakpoint

/* Dasar: mobile */
.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet */
@media (min-width: 700px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop */
@media (min-width: 1000px) {
  .cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

Dengan cara ini, layout akan berubah secara bertahap ketika viewport semakin lebar.

06 • Responsive Units

Menggunakan Satuan yang Fleksibel

Satuan CSS memengaruhi bagaimana ukuran elemen mengikuti ukuran layar atau ukuran elemen induknya.

Satuan Penjelasan Contoh
px Ukuran tetap dalam CSS pixel. width: 300px
% Persentase terhadap ukuran tertentu dari elemen induk. width: 100%
rem Relatif terhadap ukuran font elemen root. padding: 2rem
vw Persentase dari lebar viewport. width: 50vw
vh Persentase dari tinggi viewport. height: 50vh

Contoh penggunaan width 100%

.container {
  width: 100%;
  max-width: 1100px;
  margin: 0 auto;
  padding: 20px;
}

Container dapat mengikuti lebar ruang yang tersedia, tetapi tidak akan melebar melebihi 1100px.

Menggunakan clamp()

Fungsi clamp(minimum, preferred, maximum) membuat ukuran fleksibel dengan batas bawah dan atas. 

.title {
  font-size: clamp(24px, 4vw, 48px);
}

Ukuran font akan menyesuaikan viewport, tetapi tidak lebih kecil dari 24px dan tidak lebih besar dari 48px.

Gunakan satuan sesuai kebutuhan. Tidak semua ukuran harus dibuat relatif; ukuran border atau ikon tertentu tetap bisa menggunakan px.
07 • Responsive Images

Membuat Gambar Responsif

Gambar yang terlalu besar dapat menyebabkan halaman melebar melebihi layar. Salah satu solusi paling umum adalah: 

img {
  max-width: 100%;
  height: auto;
  display: block;
}

Artinya, gambar tidak akan melebihi lebar elemen induknya dan tinggi gambar akan mengikuti proporsi aslinya.

Menggunakan object-fit

.thumbnail {
  width: 100%;
  height: 200px;
  object-fit: cover;
}

object-fit: cover membuat gambar memenuhi kotak dengan tetap menjaga proporsinya. Sebagian gambar mungkin terpotong.

Sementara itu, object-fit: contain menampilkan seluruh gambar di dalam kotak, tetapi bisa menyisakan ruang kosong.

Menggunakan picture untuk sumber berbeda

<picture>
  <source
    media="(max-width: 600px)"
    srcset="gambar-mobile.jpg">

  <img
    src="gambar-desktop.jpg"
    alt="Preview project Kubika">
</picture>

Browser dapat memilih sumber gambar berdasarkan kondisi media yang cocok. Elemen img tetap menjadi fallback.

Mengenal srcset

<img
  src="gambar-800.jpg"
  srcset="
    gambar-400.jpg 400w,
    gambar-800.jpg 800w,
    gambar-1200.jpg 1200w
  "
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Contoh gambar responsif">

srcset dan sizes membantu browser memilih file gambar yang sesuai dengan ukuran tampilan dan kebutuhan resolusi.

Jangan hanya mengandalkan CSS untuk gambar berukuran besar. Pilih ukuran dan format file yang sesuai agar halaman tetap cepat dimuat.

09 • Responsive Typography

Membuat Teks Nyaman Dibaca

Ukuran teks yang nyaman pada desktop belum tentu nyaman pada smartphone. Karena itu, tipografi perlu disesuaikan. 

h1 {
  font-size: clamp(28px, 5vw, 48px);
  line-height: 1.2;
}

p {
  font-size: 16px;
  line-height: 1.7;
}

.content {
  max-width: 70ch;
}

Beberapa hal yang perlu diperhatikan:

  • Gunakan ukuran font yang mudah dibaca.
  • Hindari paragraf yang terlalu panjang tanpa jeda.
  • Atur line-height agar jarak antarbaris nyaman.
  • Batasi lebar konten agar teks tidak terlalu panjang pada layar desktop.
  • Pastikan tombol dan tautan mudah disentuh.
Responsive typography tidak selalu berarti semua teks harus menggunakan vw. Fungsi clamp() sering menjadi pilihan yang lebih terkontrol.
10 • Testing & Debugging

Menguji Website Responsif

Setelah membuat responsive layout, kita perlu menguji hasilnya pada beberapa ukuran layar.

Menggunakan Chrome DevTools

  1. Buka website melalui Google Chrome.
  2. Tekan F12 atau klik kanan lalu pilih Inspect.
  3. Klik ikon perangkat mobile/tablet (Toggle Device Toolbar).
  4. Pilih ukuran perangkat atau masukkan ukuran viewport sendiri.
  5. Periksa layout, teks, gambar, dan navigasi.

Masalah yang sering terjadi

Masalah Penyebab umum Solusi
Halaman melebar ke samping. Elemen memiliki lebar tetap terlalu besar. Gunakan max-width, width: 100%, dan periksa overflow.
Gambar terpotong. Ukuran kotak dan object-fit tidak sesuai. Atur object-fit dan ukuran gambar.
Teks terlalu kecil. Font menggunakan ukuran tetap yang terlalu kecil. Gunakan ukuran yang nyaman atau clamp().
Navbar berantakan. Ruang tidak cukup untuk seluruh menu. Atur ulang susunan atau buat menu mobile.
Kartu terlalu sempit. Kolom terlalu banyak pada layar kecil. Kurangi kolom melalui media query atau Grid responsif.

Checklist saat melakukan testing

  • Apakah ada horizontal scroll yang tidak diperlukan?
  • Apakah semua teks terbaca dengan jelas?
  • Apakah tombol mudah ditekan?
  • Apakah gambar tetap proporsional?
  • Apakah navigasi tetap mudah digunakan?
  • Apakah layout tetap rapi ketika viewport diubah?
Biasakan menguji pada beberapa lebar viewport, bukan hanya melihat hasil pada laptop sendiri.

Instruksi pengerjaan

  2. Buat navbar dengan logo dan menu navigasi.
  3. Buat hero section dengan judul dan deskripsi Kubika.
  4. Buat galeri minimal enam project menggunakan Grid.

Starter CSS

/* Dasar mobile */
* {
  box-sizing: border-box;
}

.container {
  width: 100%;
  max-width: 1200px;
  padding: 20px;
  margin: 0 auto;
}

.project-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 20px;
}

.project-card img {
  width: 100%;
  height: 200px;
  object-fit: cover;
  display: block;
}

/* Tablet */
@media (min-width: 700px) {
  .project-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

/* Desktop */
@media (min-width: 1000px) {
  .project-grid {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}

Bonus Challenge

  • Buat navigasi mobile yang lebih ringkas.
  • Gunakan clamp() pada heading.
  • Buat layout anggota yang responsif.
  • Tambahkan gambar project dengan object-fit: cover.
  • Pastikan tidak ada horizontal overflow.
  • Pastikan navigasi dapat digunakan dengan keyboard.
Standar selesai: Website dapat digunakan pada tiga kategori layar, memiliki minimal enam project, navigasi yang nyaman, dan tidak mengalami horizontal overflow yang tidak diinginkan.
