BAGIAN 01

Apa Itu CSS?

CSS merupakan singkatan dari Cascading Style Sheets. CSS adalah bahasa stylesheet yang digunakan untuk mengatur tampilan dan tata letak dokumen HTML.

Dengan CSS, kita dapat mengubah warna teks, ukuran tulisan, jenis font, background, jarak antar elemen, posisi, dan berbagai aspek visual lainnya.

Analogi Sederhana

Bayangkan sebuah rumah yang sedang dibangun. Setiap bagian memiliki perannya masing-masing.

HTML

Struktur bangunan.

  • Dinding
  • Pintu
  • Jendela
  • Ruangan

CSS

Tampilan bangunan.

  • Warna dinding
  • Desain pintu
  • Ukuran jendela
  • Interior ruangan

Perbandingan HTML dan CSS

HTML CSS
Membuat struktur konten. Mengatur tampilan konten.
Membuat heading dan paragraf. Mengatur ukuran dan warna teks.
Menampilkan gambar. Mengatur ukuran dan bentuk gambar.
Membuat bagian website. Mengatur layout bagian website.
HTML dan CSS bekerja bersama. HTML membentuk struktur, sedangkan CSS menentukan bagaimana struktur tersebut ditampilkan kepada pengguna.

BAGIAN 03

Fungsi dan Manfaat CSS

CSS bukan hanya digunakan untuk membuat website terlihat berwarna. Ada banyak fungsi penting lainnya.

1. Mengatur Warna

CSS dapat mengatur warna teks, background, border, dan elemen lainnya.

h1 { color: blue; } body { background-color: #f8fafc; }

2. Mengatur Typography

Typography berkaitan dengan tampilan tulisan, seperti jenis font, ukuran, ketebalan, dan jarak baris.

p { font-family: Arial, sans-serif; font-size: 16px; font-weight: 500; line-height: 1.7; }

3. Mengatur Jarak dan Ukuran

CSS dapat mengatur ukuran elemen serta jarak antara satu elemen dengan elemen lainnya.

.card { width: 300px; padding: 20px; margin: 15px; }

4. Mengatur Tata Letak

CSS dapat digunakan untuk menyusun elemen menggunakan Flexbox, Grid, dan berbagai teknik layout.

.container { display: flex; justify-content: center; align-items: center; gap: 20px; }

5. Membuat Website Responsif

CSS memungkinkan tampilan website menyesuaikan ukuran layar perangkat yang berbeda.

@media (max-width: 600px) { .container { flex-direction: column; } }
Responsif berarti tampilan website dapat menyesuaikan perangkat, bukan sekadar mengecilkan seluruh elemen.
BAGIAN 04

Memahami Cara Kerja CSS

CSS bekerja dengan memilih elemen HTML, kemudian memberikan aturan tampilan kepada elemen tersebut.

Struktur Dasar CSS

selector { property: value; }

Penjelasan Setiap Bagian

Bagian Pengertian
Selector Memilih elemen HTML yang ingin diberi styling.
Property Menentukan aspek tampilan yang ingin diubah.
Value Menentukan nilai dari property.
Declaration Pasangan property dan value.
Declaration Block Kumpulan deklarasi di dalam kurung kurawal.

Contoh Penggunaan

h1 { color: blue; font-size: 32px; }

Penjelasan kode di atas:

  • h1 adalah selector.
  • color adalah property untuk warna teks.
  • blue adalah value warna.
  • font-size mengatur ukuran teks.
  • 32px adalah nilai ukuran teks.
Setiap deklarasi CSS umumnya diakhiri dengan titik koma (;). Property dan value dipisahkan menggunakan titik dua (:).
BAGIAN 05

3 Cara Menghubungkan CSS dengan HTML

Ada tiga cara umum untuk menerapkan CSS pada dokumen HTML. Masing-masing memiliki cara penggunaan yang berbeda.

1. Inline CSS

Inline CSS ditulis langsung pada elemen HTML menggunakan atribut style.

<h1 style="color: blue;"> Halo Dunia! </h1>

Halo Dunia!

Contoh hasil Inline CSS.

2. Internal CSS

Internal CSS ditulis di dalam elemen <style> pada bagian <head> dokumen HTML.

<!DOCTYPE html> <html lang="id"> <head> <title>Internal CSS</title> <style> h1 { color: blue; text-align: center; } </style> </head> <body> <h1>Halo Dunia!</h1> </body> </html>

3. External CSS

External CSS ditulis pada file terpisah dengan ekstensi .css, kemudian dihubungkan dengan HTML menggunakan elemen link.

File index.html:

<!DOCTYPE html> <html lang="id"> <head> <title>External CSS</title> <link rel="stylesheet" href="style.css"> </head> <body> <h1>Halo Dunia!</h1> </body> </html>

File style.css:

h1 { color: blue; text-align: center; }

Perbandingan Ketiga Metode

Metode Lokasi CSS Penggunaan
Inline Atribut style Styling satu elemen tertentu.
Internal Elemen style Styling satu halaman HTML.
External File .css terpisah Styling yang dapat digunakan banyak halaman.
Rekomendasi DevLearn: Biasakan menggunakan External CSS untuk proyek website. Cara ini membuat struktur HTML lebih bersih dan styling lebih mudah dikelola.
BAGIAN 06

Membuat CSS Pertamamu

Sekarang waktunya mencoba langsung. Kita akan membuat halaman HTML sederhana dan menghubungkannya dengan CSS.

Langkah 1. Buat Folder Proyek

belajar-css/ │ ├── index.html │ └── style.css

Langkah 2. Buat File HTML

Buka index.html dan tulis kode berikut:

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Belajar CSS</title> <link rel="stylesheet" href="style.css"> </head> <body> <h1>Halo, Saya Sedang Belajar CSS!</h1> <p> Ini adalah halaman website pertama saya yang menggunakan CSS. </p> <button>Mulai Belajar</button> </body> </html>

Langkah 3. Buat File CSS

Buka style.css dan masukkan kode berikut:

body { font-family: Arial, sans-serif; background-color: #f8fafc; color: #334155; text-align: center; padding: 50px 20px; } h1 { color: #2563eb; font-size: 30px; } p { font-size: 16px; line-height: 1.7; } button { background-color: #2563eb; color: white; padding: 12px 20px; border: none; border-radius: 8px; cursor: pointer; }

Langkah 4. Jalankan Website

1. Simpan seluruh file.

Pastikan index.html dan style.css berada di folder yang sama.

2. Buka index.html.

Kamu bisa membukanya melalui browser atau menggunakan Live Server di VS Code.

3. Amati hasilnya.

Perhatikan bagaimana CSS mengubah tampilan halaman HTML.

Jika styling tidak muncul, periksa kembali nama file CSS dan lokasi href pada elemen link.

BAGIAN 08

Kesalahan Umum Saat Belajar CSS

Ketika mulai belajar CSS, ada beberapa kesalahan yang sering dialami pemula.

1. Salah Menulis Nama File

href="styles.css"

Padahal file yang tersedia bernama style.css. Akibatnya, browser tidak menemukan stylesheet tersebut.

2. Lupa Menggunakan Titik Koma

h1 { color: blue font-size: 30px; }

Sebaiknya setiap deklarasi diakhiri titik koma agar aturan CSS lebih konsisten.

3. Salah Menggunakan Kurung Kurawal

h1 { color: blue; font-size: 30px;

Kurung kurawal pembuka dan penutup harus digunakan dengan benar.

4. Tidak Memeriksa Lokasi File

File CSS yang berada di folder berbeda membutuhkan path yang sesuai pada atribut href.

5. Terlalu Banyak Menyalin Kode

Menyalin kode memang dapat membantu proses belajar, tetapi kamu tetap perlu memahami fungsi setiap barisnya.

Tips: Jika tampilan website tidak berubah, periksa nama file, path stylesheet, selector, dan deklarasi CSS terlebih dahulu.
