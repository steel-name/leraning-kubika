Build Your First Portfolio Website

Saatnya menggabungkan seluruh kemampuan CSS yang telah kamu pelajari untuk membangun website portofolio pribadi yang menarik, terstruktur, responsif, dan dapat dikembangkan.

📚 15 Materi Pembelajaran 💻 1 Final Project 🎯 Beginner Friendly

01. Pengenalan Proyek

Selamat datang di modul terakhir CSS! Pada sepuluh modul sebelumnya, kamu telah mempelajari berbagai konsep dasar hingga lanjutan CSS. Sekarang waktunya menerapkan semua pengetahuan tersebut ke dalam sebuah proyek nyata.

Pada proyek ini, kamu akan membuat sebuah Personal Portfolio Website. Website ini digunakan untuk memperkenalkan diri, menampilkan kemampuan, memperlihatkan hasil pekerjaan, dan menyediakan informasi kontak.

Konsep utama: Kamu tidak dituntut membuat website yang sempurna. Fokus pada struktur yang benar, tampilan yang nyaman, kode yang rapi, dan pemahaman terhadap setiap kode yang digunakan.

Hasil akhir proyek

👤

Profile

Informasi pribadi, foto, dan deskripsi singkat.

🛠️

Skills

Daftar kemampuan dan teknologi yang dipelajari.

💻

Projects

Galeri hasil pekerjaan atau latihan.

✉️

Contact

Informasi untuk menghubungi pemilik website.

Alur pembelajaran

  1. Memahami instruksi dan persyaratan proyek.
  2. Menyiapkan folder dan lingkungan kerja.
  3. Merancang tampilan website.
  4. Membangun struktur HTML.
  5. Menerapkan CSS dan layout.
  6. Menguji responsivitas dan memperbaiki kesalahan.
  7. Mengumpulkan hasil akhir.

02. Tujuan Pembelajaran

Setelah menyelesaikan proyek ini, kamu diharapkan mampu:

  1. Membangun struktur website menggunakan semantic HTML.
  2. Mengatur warna, font, ukuran, dan tampilan menggunakan CSS.
  3. Menerapkan Box Model dengan benar.
  4. Menggunakan Flexbox dan Grid untuk mengatur layout.
  5. Membuat website responsif untuk desktop, tablet, dan smartphone.
  6. Menerapkan hover, transition, transform, dan animation.
  7. Menggunakan pseudo-class dan media query.
  8. Memeriksa dan memperbaiki kesalahan CSS.
  9. Menulis kode yang rapi dan mudah dipahami.
  10. Menjelaskan hasil proyek secara mandiri.
Standar kelulusan: Peserta harus mampu menjelaskan struktur HTML dan CSS yang digunakan, bukan hanya menunjukkan hasil tampilannya.

03. Persyaratan Proyek

Website wajib memiliki komponen berikut.

Bagian Ketentuan Materi CSS
Navbar Logo dan menu navigasi. Flexbox, Position
Hero Nama, profesi atau minat, deskripsi, tombol. Typography, Colors
About Foto atau ilustrasi dan deskripsi profil. Grid, Box Model
Skills Minimal 4 kemampuan. Grid, Colors
Projects Minimal 3 kartu proyek. Grid, Transition
Contact Email atau tautan media sosial. Flexbox
Footer Informasi hak cipta. Spacing, Typography

Ketentuan teknis

  • Gunakan HTML dan CSS eksternal.
  • Gunakan semantic HTML seperti header, main, section, article, dan footer.
  • Gunakan minimal satu Flexbox dan satu CSS Grid.
  • Gunakan minimal dua media query.
  • Gunakan minimal satu efek hover dan transition.
  • Gunakan nama class yang mudah dipahami.
  • Hindari penggunaan CSS inline.
  • Pastikan tautan navigasi mengarah ke bagian yang benar.
Perhatian: Jangan hanya menyalin starter code. Kamu harus mengembangkan tampilan, mengganti konten, dan memahami fungsi setiap bagian.

06. Perencanaan Desain UI

Sebelum menulis kode CSS, tentukan terlebih dahulu bagaimana website akan terlihat.

A. Menentukan warna

Gunakan maksimal tiga sampai empat warna utama agar tampilan konsisten.

:root {
  --primary: #2563eb;
  --dark: #14213d;
  --text: #334155;
  --background: #f8fafc;
  --white: #ffffff;
}

B. Menentukan tipografi

  • Heading harus mudah dibedakan dari teks biasa.
  • Gunakan font yang mudah dibaca.
  • Hindari terlalu banyak jenis font.
  • Atur line-height agar paragraf nyaman dibaca.

C. Menentukan spacing

Spacing adalah jarak antar elemen dalam website.

.section {
  padding: 80px 8%;
}

.card {
  padding: 24px;
  margin-bottom: 20px;
}

.container {
  max-width: 1100px;
  margin: auto;
}

D. Menentukan layout

  • Flexbox untuk susunan horizontal atau vertikal satu dimensi.
  • Grid untuk susunan baris dan kolom dua dimensi.
  • Position untuk elemen yang membutuhkan posisi khusus.
Tips desain: Buat desain sederhana terlebih dahulu. Setelah struktur selesai, barulah tambahkan dekorasi dan animasi.

07. Tahapan Pengerjaan

Tahap 1 — Membuat struktur HTML

Mulailah dengan membangun bagian utama website.

<header>
  <nav>...</nav>
</header>

<main>
  <section id="home">...</section>
  <section id="about">...</section>
  <section id="skills">...</section>
  <section id="projects">...</section>
  <section id="contact">...</section>
</main>

<footer>...</footer>

Tahap 2 — Membuat navbar

Gunakan Flexbox agar logo dan navigasi tersusun rapi.

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 20px 8%;
}

Tahap 3 — Membuat Hero Section

Hero merupakan bagian pertama yang dilihat pengunjung.

  • Tambahkan nama atau identitas.
  • Tambahkan deskripsi singkat.
  • Tambahkan tombol menuju bagian proyek.

Tahap 4 — Membuat About dan Skills

Gunakan Grid atau Flexbox untuk menata foto, deskripsi, dan daftar kemampuan.

Tahap 5 — Membuat Projects

Gunakan elemen article untuk setiap kartu proyek.

  • Nama proyek.
  • Deskripsi singkat.
  • Teknologi yang digunakan.
  • Gambar atau ilustrasi proyek jika tersedia.

Tahap 6 — Membuat Contact dan Footer

Tambahkan email, media sosial, atau tautan portofolio lain.

Tahap 7 — Styling dan pengujian

Atur warna, ukuran, jarak, layout, hover, dan responsivitas.

10. Responsive Design

Responsive design adalah pendekatan untuk membuat website menyesuaikan tampilannya berdasarkan ukuran layar perangkat.

PerangkatStandar tampilan
DesktopLayout lebar, tiga kolom proyek.
TabletLayout lebih ringkas, dua kolom.
SmartphoneKonten satu kolom dan navigasi dapat membungkus.

Mengenal Media Query

/* Untuk layar maksimal 768px */
@media (max-width: 768px) {
  .container {
    grid-template-columns: 1fr;
  }
}

/* Untuk layar maksimal 480px */
@media (max-width: 480px) {
  h1 {
    font-size: 28px;
  }
}

Pengujian menggunakan browser

  1. Buka website di Google Chrome.
  2. Tekan F12 atau klik kanan lalu Inspect.
  3. Aktifkan Device Toolbar.
  4. Pilih ukuran smartphone atau tablet.
  5. Periksa seluruh bagian website.
Ingat: Jangan hanya menguji website pada satu ukuran layar. Coba beberapa ukuran agar kamu mengetahui apakah layout benar-benar fleksibel.

11. Debugging dan Optimization

Debugging adalah proses menemukan, menganalisis, dan memperbaiki kesalahan dalam program.

Kesalahan CSS yang sering terjadi

MasalahPenyebab umumSolusi
CSS tidak bekerja File CSS tidak terhubung. Periksa href pada link stylesheet.
Gambar tidak muncul Path atau nama gambar salah. Periksa lokasi dan ekstensi file.
Elemen keluar layar Ukuran elemen terlalu besar. Periksa width, padding, dan margin.
Grid tidak tersusun Pengaturan kolom tidak sesuai. Periksa grid-template-columns.
Hover tidak berfungsi Selector atau deklarasi salah. Periksa selector :hover.

Contoh debugging

Perhatikan kode berikut yang memiliki kesalahan.

.container {
  display: grid;
  grid-template-columns: repeat(3 1fr);
  gap: 20px;
}

Kesalahan terdapat pada fungsi repeat().

Perbaikannya:

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Optimasi sederhana

  • Gunakan gambar dengan ukuran yang sesuai.
  • Hindari CSS yang tidak digunakan.
  • Gunakan nama class yang konsisten.
  • Hindari terlalu banyak animasi.
  • Gunakan satu file CSS utama agar mudah dikelola.
Prinsip debugging: Jangan langsung menghapus kode ketika terjadi kesalahan. Cari tahu penyebabnya, pahami masalahnya, lalu perbaiki.

12. Tantangan Tambahan

Setelah persyaratan utama selesai, kamu dapat mengembangkan website melalui tiga tingkat tantangan berikut.

LEVEL 1 — BEGINNER

Tingkat dasar untuk memperkuat pemahaman CSS.

  1. Ubah warna utama website.
  2. Tambahkan gambar profil.
  3. Tambahkan hover pada semua kartu.
  4. Gunakan font dan ukuran heading yang konsisten.
LEVEL 2 — INTERMEDIATE

Tingkat menengah untuk mengembangkan layout dan interaksi.

  1. Buat navbar sticky.
  2. Tambahkan animasi sederhana pada hero.
  3. Buat layout project dengan variasi ukuran kartu.
  4. Tambahkan tombol kembali ke atas.
LEVEL 3 — ADVANCED

Tingkat lanjutan untuk mengembangkan website lebih jauh.

  1. Buat dark mode menggunakan JavaScript.
  2. Buat navigasi mobile menggunakan tombol menu.
  3. Tambahkan halaman detail proyek.
  4. Publikasikan website menggunakan layanan hosting statis.
Catatan: Tantangan level 3 merupakan pengembangan di luar materi inti CSS. JavaScript dan deployment tidak menjadi syarat kelulusan proyek.
