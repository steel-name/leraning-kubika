CSS FUNDAMENTAL · MODUL 03

Colors & Backgrounds

Pelajari cara menggunakan warna, transparansi, gradient, dan gambar latar untuk membuat website lebih menarik.

Level: Beginner · Estimasi: 45–60 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami penggunaan warna dalam CSS.
  • Mengenal nama warna dan format HEX, RGB, serta RGBA.
  • Mengatur warna teks dan latar belakang.
  • Memahami opacity dan transparansi.
  • Membuat background gradient sederhana.
  • Menggunakan gambar sebagai background.
  • Mengombinasikan warna agar tampilan website nyaman dilihat.
Prasyarat: Pahami CSS syntax dan selector dari Modul 01 dan Modul 02.

02. Dasar Warna dalam CSS

Warna adalah salah satu bagian penting dalam desain website. Dengan CSS, kita bisa mengatur warna teks, latar belakang, border, dan berbagai elemen lainnya.

Misalnya, sebuah website menggunakan warna biru untuk tombol, putih untuk latar belakang, dan abu-abu untuk teks. Kombinasi tersebut dapat membuat tampilan lebih teratur dan nyaman.

Tips desain: Gunakan beberapa warna utama secara konsisten. Tidak semua bagian website harus memiliki warna yang berbeda.

03. Format Penulisan Warna

CSS menyediakan beberapa cara untuk menentukan warna. Tiga format yang umum digunakan adalah named color, HEX, dan RGB/RGBA.

A. Named Color

Named color adalah penggunaan nama warna yang sudah dikenal oleh CSS, misalnya red, blue, green, dan black. 

h1 {
  color: red;
}

p {
  color: blue;
}

body {
  background-color: white;
}

B. HEX Color

HEX merupakan format warna yang menggunakan kode hexadecimal. Format umumnya ditulis dengan tanda pagar diikuti enam karakter. 

h1 {
  color: #2563eb;
}

body {
  background-color: #f8fafc;
}

button {
  background-color: #14213d;
}

Contoh kode HEX:

#FF0000
Merah
#00FF00
Hijau
#0000FF
Biru

C. RGB

RGB merupakan singkatan dari Red, Green, Blue. Warna dibentuk dari kombinasi tiga nilai tersebut. Setiap nilai umumnya berada dalam rentang 0 sampai 255. 

h1 {
  color: rgb(255, 0, 0);
}

p {
  color: rgb(0, 0, 255);
}

body {
  background-color: rgb(245, 245, 245);
}

D. RGBA

RGBA mirip dengan RGB, tetapi memiliki satu nilai tambahan yaitu alpha untuk mengatur tingkat transparansi. 

.overlay {
  background-color: rgba(0, 0, 0, 0.5);
}

Nilai alpha berada dari 0 sampai 1. Nilai 0 berarti sepenuhnya transparan, sedangkan 1 berarti sepenuhnya terlihat.

FormatContohKeterangan
NamedredMenggunakan nama warna.
HEX#ff0000Menggunakan kode hexadecimal.
RGBrgb(255,0,0)Menggunakan kombinasi merah, hijau, biru.
RGBArgba(255,0,0,.5)RGB dengan tingkat transparansi.
Catatan: Ada juga format HSL dan HSLA. Kita akan mengenalnya lebih lanjut ketika sudah memahami dasar penggunaan warna.

05. Background Color

Property background-color digunakan untuk memberikan warna pada latar belakang elemen HTML. 

body {
  background-color: #f8fafc;
}

.card {
  background-color: white;
}

button {
  background-color: #2563eb;
  color: white;
}
Contoh card

Card Informasi

Ini adalah contoh elemen yang memiliki background berwarna biru muda.

Perbedaan color dan background-color

PropertyFungsi
colorMengatur warna teks.
background-colorMengatur warna latar belakang.
Kesalahan umum: Jangan tertukar antara color dan background-color. Keduanya memiliki fungsi yang berbeda.

06. Opacity & Transparansi

Opacity digunakan untuk mengatur tingkat ketidaktransparanan suatu elemen. Nilainya berada dari 0 sampai 1. 

.box {
  opacity: 0.5;
}
Perbandingan opacity
1.0
100%
0.5
50%
0.2
20%

Perlu diingat, opacity memengaruhi seluruh elemen beserta isi di dalamnya, termasuk teks dan gambar.

Transparansi menggunakan RGBA

Jika kamu hanya ingin membuat latar belakang transparan tanpa membuat teks di dalamnya ikut transparan, gunakan RGBA. 

.card {
  background-color: rgba(37, 99, 235, 0.2);
  color: #14213d;
}
Kesimpulan: Gunakan opacity untuk mengatur transparansi seluruh elemen. Gunakan RGBA jika hanya warna tertentu yang ingin dibuat transparan.

07. CSS Gradient

Gradient adalah perpaduan dua warna atau lebih yang berubah secara bertahap. Gradient dapat membuat tampilan website lebih dinamis.

A. Linear Gradient

Linear gradient menghasilkan perpindahan warna dalam satu arah, misalnya dari kiri ke kanan atau dari atas ke bawah. 

.hero {
  background: linear-gradient(
    to right,
    #14213d,
    #2563eb
  );
}
Contoh linear gradient
Linear Gradient

B. Gradient dengan tiga warna

.banner {
  background: linear-gradient(
    to right,
    #2563eb,
    #06b6d4,
    #10b981
  );
}
Contoh tiga warna

C. Radial Gradient

Radial gradient menghasilkan perpindahan warna yang menyebar dari titik pusat ke arah luar. 

.circle {
  background: radial-gradient(
    circle,
    #06b6d4,
    #14213d
  );
}
Contoh radial gradient
Tips: Gradient cocok digunakan pada hero section, banner, tombol, dan elemen dekoratif. Jangan terlalu banyak menggunakan warna agar desain tetap nyaman dilihat.

08. Background Image

CSS juga memungkinkan kita menggunakan gambar sebagai latar belakang sebuah elemen melalui property background-image. 

.hero {
  background-image: url("gambar.jpg");
}

Selain itu, ada beberapa property yang sering digunakan bersama background image.

Background Size

background-size mengatur ukuran gambar latar. Nilai cover membuat gambar memenuhi area elemen sambil mempertahankan proporsinya. Sebagian gambar mungkin terpotong. 

.hero {
  background-image: url("gambar.jpg");
  background-size: cover;
}

Background Position

background-position mengatur posisi gambar di dalam elemen. 

.hero {
  background-position: center;
}

Background Repeat

background-repeat mengatur apakah gambar latar diulang atau tidak. 

.hero {
  background-repeat: no-repeat;
}

Contoh gabungan

.hero {
  background-image: url("gambar.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
PropertyFungsi
background-imageMenentukan gambar latar.
background-sizeMengatur ukuran gambar latar.
background-positionMengatur posisi gambar.
background-repeatMengatur pengulangan gambar.
Perhatikan: Pastikan lokasi file gambar benar. Jika gambar berada di folder images, gunakan url("images/gambar.jpg").
