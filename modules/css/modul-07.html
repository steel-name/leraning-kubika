CSS FUNDAMENTAL · MODUL 07

CSS Flexbox

Pelajari cara menyusun, meratakan, dan mengatur jarak antar elemen website dengan layout yang fleksibel.

Level: Beginner – Intermediate · Estimasi: 60–75 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami konsep Flexbox dan cara kerjanya.
  • Menggunakan display: flex.
  • Mengatur arah elemen dengan flex-direction.
  • Mengatur posisi horizontal atau main axis menggunakan justify-content.
  • Mengatur posisi cross axis menggunakan align-items.
  • Mengatur perpindahan baris menggunakan flex-wrap.
  • Mengatur jarak dengan gap.
  • Mengatur ukuran dan perilaku item dengan flex-grow, flex-shrink, dan flex-basis.
  • Mengatur item secara individual dengan align-self dan order.
Prasyarat: Pahami display, box model, margin, padding, dan dasar CSS dari modul sebelumnya.

02. Mengenal Flexbox

Flexbox atau Flexible Box Layout adalah sistem layout CSS yang membantu kita menyusun elemen secara fleksibel dalam satu dimensi.

Satu dimensi berarti Flexbox bekerja terutama dalam satu arah: horizontal atau vertikal.

Contohnya, ketika kita ingin membuat:

  • Navbar dengan logo di kiri dan menu di kanan.
  • Beberapa card dalam satu baris.
  • Tombol yang berada tepat di tengah.
  • Konten yang memiliki jarak merata.
  • Layout yang menyesuaikan ukuran layar.
Flexbox membantu mengurangi kebutuhan untuk mengatur posisi elemen secara manual menggunakan margin atau position.

03. Konsep Dasar Flexbox

Untuk menggunakan Flexbox, kita perlu membedakan dua istilah:

  • Flex Container: Elemen induk yang menggunakan display: flex.
  • Flex Items: Elemen anak langsung di dalam flex container.
.container {
  display: flex;
}

Setelah display: flex diterapkan pada container, elemen anak langsung akan menjadi flex items.

Main Axis dan Cross Axis

Flexbox memiliki dua sumbu utama yang perlu dipahami:

  • Main Axis: Sumbu utama sesuai arah flex-direction.
  • Cross Axis: Sumbu yang tegak lurus terhadap main axis.
Jika flex-direction: row, main axis berjalan horizontal. Jika flex-direction: column, main axis berjalan vertikal.

07. Flex Wrap

Secara default, flex items berusaha berada dalam satu baris. Flex-wrap mengatur apakah item boleh berpindah ke baris atau kolom berikutnya ketika ruang tidak cukup.

No Wrap

  display: flex;
  flex-wrap: nowrap;
}

Wrap

09. Mengatur Flex Items

Selain mengatur container, kita juga dapat mengatur bagaimana masing-masing item mengambil ruang.

A. Flex Grow

Flex-grow menentukan seberapa besar item dapat berkembang untuk mengisi ruang kosong yang tersedia. 

.item {
  flex-grow: 1;
}
Contoh flex grow
Grow 1
Grow 2
Grow 1

Item kedua mendapat bagian ruang kosong dua kali lipat dibandingkan item pertama dan ketiga.

B. Flex Shrink

Flex-shrink menentukan seberapa besar item dapat menyusut ketika ruang tidak mencukupi. 

.item {
  flex-shrink: 1;
}

Nilai default umumnya 1. Jika menggunakan 0, item tidak akan menyusut karena pembagian ruang negatif Flexbox.

C. Flex Basis

Flex-basis menentukan ukuran awal item sebelum ruang yang tersisa dibagikan atau dikurangi. 

.item {
  flex-basis: 200px;
}

D. Shorthand Flex

Ketiga property tersebut dapat ditulis dalam satu deklarasi. 

.item {
  flex: 1 1 200px;
}

/* grow shrink basis */
PropertyFungsi
flex-growMengatur kemampuan berkembang.
flex-shrinkMengatur kemampuan menyusut.

flexShorthand ketiga property.
Contoh penggunaan: flex: 1 sering digunakan untuk membagi ruang secara merata di antara beberapa item.

11. Order

Property order digunakan untuk mengubah urutan visual flex items tanpa mengubah urutan HTML. 

.item-first {
  order: 1;
}

.item-last {
  order: 3;
}
Contoh order
HTML 1
HTML 2
HTML 3

Urutan tampil: HTML 2 → HTML 3 → HTML 1.

Order hanya mengubah urutan visual. Urutan pembacaan dokumen dan navigasi keyboard tidak otomatis berubah. Jangan menggunakannya untuk menggantikan struktur HTML yang logis.
