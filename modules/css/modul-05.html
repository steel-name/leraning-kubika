CSS FUNDAMENTAL · MODUL 05

CSS Box Model

Pelajari bagaimana ukuran, ruang, dan batas setiap elemen HTML bekerja menggunakan Content, Padding, Border, dan Margin.

Level: Beginner · Estimasi: 45–60 menit

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami konsep CSS Box Model.
  • Menjelaskan fungsi Content, Padding, Border, dan Margin.
  • Mengatur ruang di dalam elemen menggunakan Padding.
  • Mengatur batas elemen menggunakan Border.
  • Mengatur jarak antar elemen menggunakan Margin.
  • Memahami penggunaan Width dan Height.
  • Menggunakan Box Sizing untuk mengontrol perhitungan ukuran.
  • Memahami dasar Overflow.
Prasyarat: Pahami HTML dasar dan materi CSS sebelumnya, terutama selector, warna, dan typography.

02. Mengenal CSS Box Model

Setiap elemen HTML yang ditampilkan oleh browser pada dasarnya memiliki bentuk kotak atau box.

CSS Box Model adalah konsep yang menjelaskan bagaimana ukuran sebuah elemen dibentuk oleh empat bagian utama:

  1. Content: Bagian utama yang berisi teks, gambar, atau konten lainnya.
  2. Padding: Ruang antara content dan border.
  3. Border: Garis batas yang mengelilingi elemen.
  4. Margin: Ruang di luar border untuk memisahkan elemen dari elemen lain.

Ingat urutannya: Content → Padding → Border → Margin. Mulai dari bagian paling dalam menuju bagian paling luar.

03. Content

Content merupakan bagian utama dari sebuah elemen HTML. Bagian ini dapat berisi teks, gambar, video, atau elemen lainnya.

Ukuran content umumnya dapat diatur menggunakan property width dan height. 

.box {
  width: 250px;
  height: 120px;
  background-color: #bfdbfe;
}

Pada contoh tersebut, area content memiliki lebar 250px dan tinggi 120px.

04. Padding

Padding adalah ruang kosong di antara content dan border. Padding membuat isi elemen tidak terlalu dekat dengan batas kotaknya.

Contoh penggunaan padding

.card {
  background-color: #dbeafe;
  padding: 20px;
}
Perbandingan padding
Tanpa Padding
Padding 20px

Mengatur padding secara terpisah

.box {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 30px;
  padding-left: 40px;
}

Penjelasannya:

PropertyFungsi
padding-topJarak bagian atas.
padding-rightJarak bagian kanan.
padding-bottomJarak bagian bawah.
padding-leftJarak bagian kiri.
Contoh nyata: Ketika membuat tombol website, padding digunakan agar teks di dalam tombol memiliki ruang yang nyaman.

05. Border

Border adalah garis batas yang mengelilingi content dan padding. Border dapat diatur melalui ketebalan, jenis garis, dan warna.

Contoh penggunaan border

.card {
  border: 2px solid #2563eb;
}

border-styleMengatur jenis garis.
border-colorMengatur warna garis.

06. Margin

Margin adalah ruang kosong di luar border. Fungsinya untuk memberikan jarak antara satu elemen dengan elemen lainnya. 

.card {
  margin: 20px;
}
Perbandingan margin
Box pertama
Box kedua dengan margin-top: 20px

Mengatur margin secara terpisah

.box {
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 30px;
  margin-left: 40px;
}

Margin auto

Margin juga dapat digunakan untuk menempatkan elemen di tengah secara horizontal. 

.container {
  width: 500px;
  max-width: 100%;
  margin: 0 auto;
}
Contoh margin auto
Elemen di tengah
Perbedaan penting: Padding memberikan ruang di dalam border, sedangkan margin memberikan ruang di luar border.

07. Shorthand Padding & Margin

Shorthand adalah cara menulis beberapa property CSS dalam satu deklarasi yang lebih ringkas.

Satu nilai

.box {
  padding: 20px;
}

Semua sisi mendapatkan nilai 20px.

Dua nilai

.box {
  padding: 10px 20px;
}

Nilai pertama untuk atas dan bawah. Nilai kedua untuk kanan dan kiri.

Tiga nilai

.box {
  padding: 10px 20px 30px;
}

Urutannya adalah atas, kanan-kiri, kemudian bawah.

Empat nilai

.box {
  padding: 10px 20px 30px 40px;
}

Urutannya mengikuti arah jarum jam: atas → kanan → bawah → kiri.

PenulisanAtasKananBawahKiri
10px10101010
10px 20px10201020
10px 20px 30px10203020
10px 20px 30px 40px10203040
Jangan tertukar: Urutan empat nilai shorthand selalu mengikuti arah jarum jam, dimulai dari atas.

08. Width & Height

Property width dan height digunakan untuk menentukan lebar dan tinggi sebuah elemen. 

.box {
  width: 300px;
  height: 150px;
}

Min dan Max

Selain ukuran tetap, CSS menyediakan batas ukuran minimum dan maksimum. 

.container {
  width: 100%;
  max-width: 900px;
  min-height: 300px;
}
PropertyFungsi
widthMenentukan lebar.
heightMenentukan tinggi.
min-widthMenentukan lebar minimum.
max-widthMenentukan lebar maksimum.
min-heightMenentukan tinggi minimum.
max-heightMenentukan tinggi maksimum.
Tips responsive: Kombinasi width: 100% dan max-width sering digunakan agar elemen dapat mengikuti layar tetapi tidak menjadi terlalu lebar.

09. Box Sizing

Salah satu hal yang sering membingungkan pemula adalah perhitungan ukuran elemen ketika padding dan border ditambahkan.

A. Content-box

Ini adalah nilai default box-sizing. Width dan height hanya menghitung area content. Padding dan border ditambahkan di luar ukuran tersebut. 

.box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid #2563eb;
}

Perhitungan lebar total:

200px + 40px + 10px = 250px

Content + Padding kiri/kanan + Border kiri/kanan

B. Border-box

Dengan border-box, width dan height sudah mencakup content, padding, dan border. 

.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid #2563eb;
}
Lebar total tetap 200px

Padding dan border masuk ke dalam ukuran yang ditentukan.

Perbandingan

JenisPerhitungan lebarTotal
content-box200 + 40 + 10250px
border-boxUkuran sudah termasuk padding dan border200px

Best Practice

Banyak developer menggunakan aturan berikut di awal CSS agar perhitungan ukuran elemen lebih mudah dikontrol. 

*,
*::before,
*::after {
  box-sizing: border-box;
}
Rekomendasi: Biasakan menggunakan border-box pada project baru. Dengan begitu, pengaturan width dan height lebih mudah diprediksi.

10. Overflow

Overflow mengatur apa yang terjadi ketika isi sebuah elemen melebihi ruang yang tersedia. 

.box {
  width: 200px;
  height: 100px;
  overflow: auto;
}

Jenis overflow

NilaiFungsi
visibleKonten dapat terlihat keluar dari kotak. Ini nilai default.
hiddenBagian konten yang keluar akan dipotong.
scrollMenampilkan mekanisme scroll.
autoScroll muncul ketika memang dibutuhkan.
Contoh overflow auto
Ini adalah contoh konten yang lebih panjang daripada ruang yang tersedia. Karena elemen menggunakan overflow auto, browser menyediakan scroll ketika konten tidak muat di dalam kotak. Tambahkan beberapa kalimat lagi untuk melihat bagaimana scroll bekerja.
Contoh penggunaan: Overflow sering digunakan pada area komentar, panel kode, tabel lebar, dan kontainer dengan tinggi terbatas.

Buat halaman sederhana bertema Product Card. Latihan ini akan membantu kamu memahami hubungan antara padding, margin, border, dan ukuran elemen.

</body>
</html>

Tugas eksplorasi

  1. Ubah padding pada product-content.
  2. Ubah margin pada judul dan harga.
  3. Tambahkan border pada product-card.
  4. Ubah border-radius menjadi 20px.
  5. Coba gunakan box-sizing: content-box, lalu bandingkan dengan border-box.
  6. Tambahkan max-width agar card tidak terlalu lebar.
Target latihan: Kamu mampu membuat product card dengan ukuran, jarak, dan batas elemen yang terkontrol.
