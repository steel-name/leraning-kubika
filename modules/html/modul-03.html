MODULE 03 • HTML BEGINNER

Heading & Paragraph

Belajar membuat judul, subjudul, dan paragraf untuk menyusun konten halaman website agar lebih terstruktur, mudah dibaca, dan mudah dipahami.

📖 Materi: HTML ⏱ Estimasi: 35–45 menit 🎯 Level: Pemula

01. Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami fungsi heading dalam HTML.
  • Menggunakan heading dari H1 sampai H6.
  • Membuat paragraf menggunakan tag P.
  • Memahami perbedaan BR dan HR.
  • Menyusun konten HTML secara terstruktur.
  • Membuat halaman artikel sederhana.
Mindset belajar: Jangan hanya menghafal nama tag. Pahami kapan dan mengapa sebuah elemen digunakan.

02. Mengenal Heading HTML

Heading adalah elemen HTML yang digunakan untuk membuat judul dan subjudul pada halaman website. Heading membantu pembaca memahami susunan informasi.

HTML menyediakan enam tingkat heading, yaitu <h1> sampai <h6>.

Contoh penggunaan heading

heading.html 
<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<h3>Bagian Ketiga</h3>
<h4>Bagian Keempat</h4>
<h5>Bagian Kelima</h5>
<h6>Bagian Keenam</h6>

Hasil tampilan di browser

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

Perbedaan tingkat heading

Tag Fungsi Penggunaan
H1 Judul utama Judul halaman
H2 Subjudul utama Bagian besar konten
H3 Subbagian Bagian di dalam H2
H4 Subbagian lanjutan Bagian di dalam H3
H5 Heading tingkat lima Subbagian lanjutan
H6 Heading tingkat enam Subbagian terdalam
Ingat: Heading bukan sekadar ukuran tulisan. Heading menunjukkan hierarki dan struktur informasi.

Aturan penggunaan heading

  • Gunakan H1 untuk judul utama halaman.
  • Gunakan H2 untuk bagian utama di bawah H1.
  • Gunakan H3 untuk subbagian dari H2.
  • Jangan memilih heading hanya karena ukuran tulisannya.
  • Jaga urutan heading agar struktur dokumen mudah dipahami.
Kesalahan umum: Menggunakan H1, lalu langsung H4 hanya karena ingin mendapatkan ukuran tulisan yang lebih kecil. Untuk mengatur ukuran visual, gunakan CSS.

03. Mengenal Paragraph

Paragraph atau paragraf adalah elemen HTML untuk menampilkan kumpulan kalimat dalam satu blok teks.

Untuk membuat paragraf, kita menggunakan tag <p>.

Contoh kode

paragraph.html 
<h1>Tentang Saya</h1>

<p>
  Halo, nama saya Budi.
  Saya sedang belajar HTML.
</p>

<p>
  Saya ingin menjadi seorang web developer.
</p>

Hasil tampilan di browser

Tentang Saya

Halo, nama saya Budi. Saya sedang belajar HTML.

Saya ingin menjadi seorang web developer.

Mengapa menggunakan tag P?

  • Mengelompokkan kalimat menjadi paragraf.
  • Membuat konten lebih terstruktur.
  • Membantu browser dan teknologi pembaca layar memahami konten.
  • Memudahkan pengaturan tampilan menggunakan CSS.
Catatan: Browser biasanya memberikan jarak otomatis di sekitar paragraf. Jarak tersebut dapat diatur menggunakan CSS.

04. Mengenal Line Break (BR)

Tag <br> digunakan untuk membuat baris baru tanpa memulai paragraf baru.

Contoh kode

line-break.html 
<p>
  Nama: Budi Santoso<br>
  Kelas: Sistem Informasi<br>
  Kampus: LPKIA
</p>

Hasil tampilan di browser

Nama: Budi Santoso
Kelas: Sistem Informasi
Kampus: LPKIA

Perhatian: Jangan menggunakan BR berkali-kali hanya untuk membuat jarak antarbagian. Gunakan CSS margin atau padding untuk mengatur jarak.

05. Mengenal Horizontal Rule (HR)

Tag <hr> digunakan untuk membuat pemisah tematik antara dua bagian konten. Biasanya browser menampilkannya sebagai garis horizontal.

Contoh kode

horizontal-rule.html 
<h2>Tentang Kami</h2>
<p>Kami sedang belajar membuat website.</p>

<hr>

<h2>Hubungi Kami</h2>
<p>Email: hello@example.com</p>

Hasil tampilan di browser

Tentang Kami

Kami sedang belajar membuat website.

Hubungi Kami

Email: hello@example.com

Perbedaan BR dan HR: BR membuat baris baru, sedangkan HR memberikan pemisah tematik antarbagian konten.

06. Menyusun Struktur Konten

Dalam website, heading dan paragraf biasanya digunakan bersama untuk membentuk susunan informasi.

Bayangkan kamu sedang membuat artikel. Ada judul utama, beberapa subjudul, lalu paragraf yang menjelaskan setiap subjudul.

Contoh struktur artikel

article.html 
<h1>Belajar Web Development</h1>

<p>
  Web development adalah proses membuat
  dan mengembangkan website.
</p>

<h2>Apa Itu HTML?</h2>

<p>
  HTML digunakan untuk menyusun struktur
  halaman website.
</p>

<h2>Apa Itu CSS?</h2>

<p>
  CSS digunakan untuk mengatur tampilan
  halaman website.
</p>

Hasil tampilan di browser

Belajar Web Development

Web development adalah proses membuat dan mengembangkan website.

Apa Itu HTML?

HTML digunakan untuk menyusun struktur halaman website.

Apa Itu CSS?

CSS digunakan untuk mengatur tampilan halaman website.

Tips developer: Biasakan menyusun konten dari judul utama, subjudul, lalu paragraf. Struktur yang rapi akan memudahkan proses pengembangan website.

07. Guided Practice

Sekarang kita coba membuat sebuah halaman artikel sederhana menggunakan elemen yang sudah dipelajari.

Langkah pengerjaan

  1. Buat file baru bernama artikel.html.
  2. Buat struktur dasar HTML.
  3. Tambahkan satu judul utama menggunakan H1.
  4. Tambahkan paragraf pengenalan.
  5. Tambahkan dua subjudul menggunakan H2.
  6. Tambahkan paragraf di bawah masing-masing subjudul.
  7. Gunakan HR sebagai pemisah jika diperlukan.

Contoh hasil kode

artikel.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>Artikel Pertamaku</title>
</head>

<body>

  <h1>Perjalanan Menjadi Developer</h1>

  <p>
    Saya sedang mempelajari dunia web development
    dari dasar.
  </p>

  <h2>Mengapa Belajar Coding?</h2>

  <p>
    Coding membantu kita membangun solusi
    menggunakan teknologi.
  </p>

  <h2>Target Saya</h2>

  <p>
    Saya ingin mampu membuat website
    sendiri dari awal.
  </p>

</body>
</html>

08. Knowledge Check

Uji pemahamanmu sebelum melanjutkan ke coding challenge. Pilih satu jawaban yang paling tepat.

1. Tag apa yang digunakan untuk membuat judul utama?

2. Berapa jumlah tingkatan heading dalam HTML?

3. Tag apa yang digunakan untuk membuat paragraf?

4. Apa fungsi dari tag BR?

5. Apa fungsi dari tag HR?

6. Apakah heading dipilih hanya berdasarkan ukuran teks?

09. Coding Challenge

Sekarang waktunya membuat halaman artikel tentang dirimu sendiri. Gunakan semua konsep yang sudah dipelajari pada modul ini.

Project: My Personal Introduction

Buat sebuah halaman HTML yang memiliki ketentuan:

  • Memiliki satu judul utama menggunakan H1.
  • Memiliki minimal tiga subjudul menggunakan H2.
  • Memiliki minimal tiga paragraf menggunakan P.
  • Memiliki minimal satu penggunaan BR.
  • Memiliki minimal satu penggunaan HR.
  • Memiliki struktur heading yang masuk akal.

Checklist penyelesaian

Standar penyelesaian: Pastikan halaman bisa dibuka di browser dan seluruh elemen tampil sesuai tujuan. Jangan hanya menyalin contoh, cobalah menulis kode sendiri.

10. Review & Kesimpulan

Pada modul ini kita sudah mempelajari empat elemen penting untuk menyusun konten HTML.

Elemen Fungsi
H1 - H6 Membuat judul dan subjudul berdasarkan hierarki.
P Membuat paragraf.
BR Membuat baris baru.
HR Membuat pemisah tematik.

Pertanyaan refleksi

  1. Apa perbedaan H1 dan H2?
  2. Mengapa kita perlu menggunakan tag P?
  3. Kapan sebaiknya menggunakan BR?
  4. Mengapa struktur heading perlu diperhatikan?
