HTML LEARNING PATH • MODUL 06

Lists, Tables & Forms

Belajar membuat daftar, menyajikan data dalam tabel, dan membuat formulir untuk menerima informasi dari pengguna.

Beginner Level Estimated Time: 60–90 Menit

Pengantar Pembelajaran

Dalam sebuah website, informasi tidak selalu disajikan menggunakan paragraf. Terkadang kita membutuhkan daftar, tabel, atau formulir agar informasi lebih mudah dipahami.

Tujuan Pembelajaran

  • Memahami fungsi HTML Lists.
  • Membuat daftar menggunakan ul dan ol.
  • Menyajikan data menggunakan HTML Tables.
  • Memahami struktur tabel dan penggabungan sel.
  • Membuat formulir menggunakan HTML Forms.
  • Mengenal berbagai jenis input pada HTML.
Alur belajar: Pahami konsep → Perhatikan contoh → Coba sendiri → Kerjakan tantangan.
BAGIAN 01

HTML Lists

HTML Lists digunakan untuk menampilkan sekumpulan informasi dalam bentuk daftar. Contohnya daftar anggota, daftar tugas, atau langkah-langkah pengerjaan.

A. Unordered List

Unordered List adalah daftar yang tidak memiliki urutan angka. Biasanya ditampilkan dengan simbol bullet. Tag yang digunakan adalah <ul> dan <li>.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
Hasil:
  • HTML
  • CSS
  • JavaScript

B. Ordered List

Ordered List digunakan ketika urutan daftar memiliki arti atau tahapan. Tag yang digunakan adalah <ol> dan <li>.

<ol> <li>Buka Visual Studio Code</li> <li>Buat file HTML</li> <li>Jalankan di browser</li> </ol>
Hasil:
  1. Buka Visual Studio Code
  2. Buat file HTML
  3. Jalankan di browser

C. Description List

Description List digunakan untuk menampilkan istilah beserta penjelasannya.

<dl> <dt>HTML</dt> <dd>Bahasa markup untuk struktur web.</dd> <dt>CSS</dt> <dd>Bahasa untuk mengatur tampilan web.</dd> </dl>

D. Nested List

Nested List adalah daftar yang berada di dalam daftar lain. Teknik ini berguna untuk membuat kategori dan subkategori.

<ul> <li>Frontend <ul> <li>HTML</li> <li>CSS</li> </ul> </li> <li>Backend</li> </ul>
Ingat: Gunakan ul untuk daftar tanpa urutan, ol untuk daftar berurutan, dan li untuk setiap item daftar.
BAGIAN 02

HTML Tables

HTML Tables digunakan untuk menampilkan data dalam bentuk baris dan kolom. Contohnya data mahasiswa, jadwal perkuliahan, dan daftar nilai.

A. Struktur Dasar Tabel

Tag Fungsi
tableMembuat tabel
trMembuat baris
thMembuat sel judul
tdMembuat sel data
captionMemberikan judul tabel

B. Contoh Membuat Tabel

<table border="1"> <caption>Data Anggota Kubika</caption> <tr> <th>Nama</th> <th>Divisi</th> </tr> <tr> <td>Biran</td> <td>Frontend</td> </tr> <tr> <td>Andi</td> <td>Backend</td> </tr> </table>
Hasil:
Data Anggota Kubika
NamaDivisi
BiranFrontend
AndiBackend

C. Thead, Tbody, dan Tfoot

Ketiga elemen ini membantu mengelompokkan bagian tabel agar strukturnya lebih jelas.

<table> <thead> <tr> <th>Produk</th> <th>Harga</th> </tr> </thead> <tbody> <tr> <td>Keyboard</td> <td>150000</td> </tr> </tbody> <tfoot> <tr> <td>Total</td> <td>150000</td> </tr> </tfoot> </table>

D. Colspan dan Rowspan

Colspan digunakan untuk menggabungkan beberapa kolom. Rowspan digunakan untuk menggabungkan beberapa baris.

Informasi Anggota
Nama Biran
<td colspan="2">Informasi Anggota</td> <td rowspan="2">Frontend</td>

E. Aksesibilitas Tabel

Gunakan atribut scope pada elemen th untuk membantu pembaca layar memahami hubungan antara judul dan data.

<th scope="col">Nama</th> <th scope="col">Divisi</th>
Gunakan tabel untuk data yang memang memiliki hubungan baris dan kolom, bukan untuk mengatur layout seluruh halaman.
BAGIAN 03

HTML Forms

HTML Forms digunakan untuk menerima data atau informasi dari pengguna. Contohnya formulir pendaftaran, login, pencarian, dan kontak.

A. Struktur Dasar Form

Elemen form menjadi wadah untuk berbagai jenis input. Setiap input dapat memiliki label agar pengguna tahu informasi apa yang harus dimasukkan.

<form action="/daftar" method="post"> <label for="nama">Nama Lengkap</label> <input type="text" id="nama" name="nama"> <button type="submit">Daftar</button> </form>

B. Mengenal Elemen Form

ElemenFungsi
formWadah formulir
labelMemberikan keterangan input
inputMenerima berbagai jenis data
textareaMenerima teks panjang
selectMembuat pilihan dropdown
optionIsi pilihan dropdown
buttonMembuat tombol

C. Jenis Input HTML

TypeFungsi
textMemasukkan teks
emailMemasukkan alamat email
passwordMemasukkan kata sandi
numberMemasukkan angka
dateMemilih tanggal
radioMemilih satu opsi
checkboxMemilih satu atau beberapa opsi
fileMengunggah berkas
submitMengirim formulir

D. Contoh Formulir Pendaftaran

<form> <label for="nama">Nama Lengkap</label> <input type="text" id="nama" name="nama" placeholder="Masukkan nama" required> <label for="email">Email</label> <input type="email" id="email" name="email" placeholder="nama@email.com" required> <label for="divisi">Pilih Divisi</label> <select id="divisi" name="divisi"> <option value="frontend">Frontend</option> <option value="backend">Backend</option> <option value="uiux">UI/UX</option> </select> <button type="submit">Daftar</button> </form>

E. Atribut Penting Form

AtributFungsi
nameNama data saat dikirim
idIdentitas elemen
placeholderPetunjuk di dalam input
requiredMewajibkan input diisi
valueNilai dari sebuah input

Catatan penting: HTML hanya membentuk struktur formulir. Untuk benar-benar menyimpan atau mengirim data ke server, dibutuhkan backend seperti PHP atau Laravel. Contoh formulir di atas hanya simulasi tampilan dan validasi browser.
GUIDED PRACTICE

Latihan Terarah

Sekarang kita akan menggabungkan tiga materi yang telah dipelajari menjadi satu halaman sederhana.

Studi Kasus: Data Anggota Kubika

Buat halaman yang memiliki:

  1. Judul halaman.
  2. Daftar divisi menggunakan unordered list.
  3. Tabel data anggota.
  4. Formulir pendaftaran anggota baru.
<h1>Data Anggota Kubika</h1> <h2>Divisi Kubika</h2> <ul> <li>Frontend</li> <li>Backend</li> <li>UI/UX</li> </ul> <h2>Anggota</h2> <table border="1"> <tr> <th>Nama</th> <th>Divisi</th> </tr> <tr> <td>Biran</td> <td>Frontend</td> </tr> </table> <h2>Pendaftaran</h2> <form> <input type="text" name="nama" placeholder="Nama lengkap"> <button type="submit">Daftar</button> </form>
Cobalah mengetik ulang kode tersebut, bukan hanya menyalinnya. Tujuannya agar kamu mulai terbiasa menulis struktur HTML sendiri.

CODING CHALLENGE

Mini Project: Student Data Management

Buat sebuah halaman HTML sederhana untuk mengelola informasi mahasiswa.

Ketentuan Project

  • Gunakan heading sebagai judul halaman.
  • Buat daftar jurusan menggunakan ul.
  • Buat tabel data minimal 3 mahasiswa.
  • Gunakan thead dan tbody.
  • Buat formulir pendaftaran mahasiswa.
  • Gunakan minimal 4 jenis input.
  • Gunakan label pada setiap input.
  • Pastikan struktur HTML tersusun rapi.

Struktur Formulir Minimal

  • Nama lengkap.
  • Email.
  • Tanggal lahir.
  • Jurusan.
  • Jenis kelamin.
  • Tombol daftar.
Target: Kamu mampu menggabungkan Lists, Tables, dan Forms tanpa harus melihat contoh kode secara terus-menerus.
