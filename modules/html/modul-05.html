MODULE 05 · HTML FUNDAMENTALS

Links & Images

Pelajari cara menghubungkan halaman website menggunakan hyperlink dan menampilkan gambar menggunakan elemen HTML.

◷ 45–60 Menit ◎ Beginner ⌘ HTML

Learning Objectives

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

  • Memahami fungsi hyperlink dalam HTML.
  • Menggunakan elemen <a> dan atribut href.
  • Membuat link eksternal, internal, email, dan telepon.
  • Menampilkan gambar menggunakan elemen <img>.
  • Memahami penggunaan src, alt, dan ukuran gambar.
  • Menggunakan relative path untuk mengakses file gambar.

1. Apa Itu Hyperlink?

Hyperlink atau link adalah elemen yang memungkinkan pengguna berpindah dari satu halaman ke halaman lainnya, membuka website lain, atau menuju bagian tertentu dalam halaman.

Contohnya ketika kamu menekan tulisan "Kunjungi Google", browser akan mengarahkanmu ke website Google.

Mengenal elemen <a>

Dalam HTML, hyperlink dibuat menggunakan elemen <a>, yang disebut anchor element.

HTML 
<a href="https://www.google.com">
  Kunjungi Google
</a>
Hasil tampilan:

Kunjungi Google
Ingat: Elemen <a> membuat sebuah teks atau elemen menjadi link yang dapat diklik.

2. Mengenal Atribut href

Atribut href digunakan untuk menentukan alamat tujuan dari sebuah hyperlink.

HTML 
<a href="https://www.youtube.com">
  Buka YouTube
</a>

Penjelasan:

  • <a> adalah elemen hyperlink.
  • href adalah atribut tujuan link.
  • URL adalah alamat website yang dituju.
  • Teks di antara tag adalah bagian yang diklik pengguna.
Tanpa atribut href, elemen anchor tidak memiliki tujuan navigasi seperti hyperlink biasa.

3. Jenis-Jenis Link

A. External Link

External link adalah link yang mengarah ke website atau domain lain.

HTML 
<a href="https://www.wikipedia.org">
  Buka Wikipedia
</a>

B. Internal Link

Internal link dapat mengarah ke halaman lain dalam website yang sama.

HTML 
<a href="about.html">
  Tentang Kami
</a>

Contoh tersebut mengarah ke file about.html yang berada dalam folder yang sama.

C. Link ke Bagian Halaman

Kita juga dapat membuat link menuju bagian tertentu pada halaman menggunakan atribut id.

HTML 
<a href="#kontak">
  Pergi ke Kontak
</a>

<h2 id="kontak">Hubungi Kami</h2>

D. Email Link

Gunakan mailto: untuk membuka aplikasi email.

HTML 
<a href="mailto:hello@example.com">
  Kirim Email
</a>

E. Telephone Link

Gunakan tel: untuk membuat link nomor telepon.

HTML 
<a href="tel:+6281234567890">
  Hubungi Kami
</a>

4. Mengenal Atribut target

Atribut target menentukan tempat link dibuka.

Atribut Fungsi
_self Membuka link pada tab yang sama.
_blank Membuka link pada tab atau jendela baru.
_parent Membuka link pada parent browsing context.
_top Membuka link pada keseluruhan jendela.
HTML 
<a
  href="https://www.google.com"
  target="_blank"
  rel="noopener noreferrer"
>
  Buka Google di Tab Baru
</a>
Saat menggunakan target="_blank", tambahkan rel="noopener noreferrer" sebagai praktik keamanan dan privasi yang baik.

5. Menampilkan Gambar dengan HTML

Website tidak hanya berisi teks. Kita juga dapat menampilkan gambar untuk memberikan informasi dan membuat halaman lebih menarik.

HTML menggunakan elemen <img> untuk menampilkan gambar.

HTML 
<img
  src="gambar.jpg"
  alt="Pemandangan gunung"
>

Penjelasan atribut:

  • src: menentukan lokasi atau sumber gambar.
  • alt: memberikan teks alternatif untuk gambar.

Mengatur Ukuran Gambar

Kita dapat menggunakan atribut width dan height untuk menentukan dimensi gambar.

HTML 
<img
  src="gambar.jpg"
  alt="Pemandangan gunung"
  width="400"
  height="250"
>
Nilai width dan height pada HTML umumnya menggunakan satuan piksel jika ditulis sebagai angka. Pastikan perbandingan dimensinya sesuai dengan gambar agar tidak terlihat gepeng atau terdistorsi.

Contoh Tampilan Gambar

Contoh gambar yang ditampilkan melalui URL.

6. Memahami Image Path

Image path adalah alamat atau lokasi file gambar yang ingin ditampilkan pada halaman HTML.

A. Gambar dalam Folder yang Sama

Struktur File 
project/
├── index.html
└── gambar.jpg

Karena gambar berada dalam folder yang sama:

HTML 
<img src="gambar.jpg" alt="Contoh gambar">

B. Gambar dalam Folder images

Struktur File 
project/
├── index.html
└── images/
    └── pemandangan.jpg

Gunakan nama folder sebelum nama file:

HTML 
<img
  src="images/pemandangan.jpg"
  alt="Pemandangan alam"
>

C. Mengakses Folder Sebelumnya

Gunakan ../ untuk naik satu tingkat dari folder saat ini.

Struktur File 
project/
├── images/
│   └── logo.png
└── pages/
    └── about.html

Dari about.html, akses logo dengan:

HTML 
<img src="../images/logo.png" alt="Logo">
Perhatikan penulisan nama file dan ekstensi. Pada banyak server, Foto.jpg dan foto.jpg dianggap berbeda. Hindari menggunakan alamat lokal komputer seperti C:\Users\... untuk website yang akan dipublikasikan.

7. Pentingnya Atribut alt

Atribut alt memberikan deskripsi teks tentang gambar. Deskripsi ini membantu pengguna pembaca layar memahami isi gambar dan dapat ditampilkan ketika gambar gagal dimuat.

Contoh yang baik

HTML 
<img
  src="kucing.jpg"
  alt="Seekor kucing putih sedang duduk di sofa"
>

Contoh yang kurang baik

HTML 
<img src="kucing.jpg" alt="gambar">
Tips: Jelaskan informasi penting dari gambar secara singkat. Untuk gambar dekoratif yang tidak menyampaikan informasi, gunakan alt="".

8. Guided Practice

Sekarang kita akan membuat halaman profil sederhana yang berisi gambar, link media sosial, dan informasi singkat.

Struktur Folder

Project Structure 
profil-saya/
├── index.html
└── images/
    └── profil.jpg

Source Code

index.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>Profil Saya</title>
</head>
<body>

  <h1>Halo, Saya Biran!</h1>

  <img
    src="images/profil.jpg"
    alt="Foto profil saya"
    width="200"
    height="200"
  >

  <h2>Tentang Saya</h2>
  <p>
    Saya sedang belajar HTML untuk
    membangun website pertama saya.
  </p>

  <h2>Media Sosial</h2>

  <a href="https://www.instagram.com"
     target="_blank"
     rel="noopener noreferrer">
    Instagram
  </a>

  <br>

  <a href="https://github.com"
     target="_blank"
     rel="noopener noreferrer">
    GitHub
  </a>

  <h2 id="kontak">Kontak</h2>

  <a href="mailto:hello@example.com">
    Kirim Email
  </a>

</body>
</html>
Ganti profil.jpg dengan foto milikmu sendiri dan sesuaikan alamat media sosial serta email sebelum menjalankan file.

10. Coding Challenge

Saatnya membuat halaman web sederhana tanpa menyalin seluruh kode Guided Practice.

Project: My Favorite Place

Buat halaman HTML tentang tempat favoritmu.

Persyaratan:
  1. Buat judul halaman menggunakan <h1>.
  2. Tampilkan satu gambar tempat favoritmu.
  3. Gunakan atribut alt yang deskriptif.
  4. Buat paragraf yang menjelaskan tempat tersebut.
  5. Tambahkan link menuju website informasi tempat tersebut.
  6. Buat link email menggunakan mailto:.
  7. Pastikan gambar dan link berfungsi dengan baik.
