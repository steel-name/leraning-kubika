HTML LEARNING PATH • MODUL 08

HTML Mini Project

Saatnya menggabungkan seluruh materi HTML yang telah dipelajari menjadi sebuah website sederhana dari awal.

Final HTML Module Beginner Level 90–120 Menit

Pengantar Pembelajaran

Selamat! Kamu telah mempelajari berbagai elemen HTML, mulai dari heading, paragraf, formatting, gambar, tautan, daftar, tabel, formulir, hingga semantic HTML.

Sekarang kita akan menerapkan semuanya dalam satu proyek sederhana, yaitu membuat Personal Profile Website.

Tujuan Pembelajaran

  • Membuat website dari file kosong.
  • Menggabungkan materi HTML Modul 01–07.
  • Membuat struktur website yang rapi.
  • Menggunakan CSS untuk mempercantik tampilan.
  • Menguji website melalui browser.
  • Memahami dasar proses pembuatan website.
Prinsip utama: Jangan hanya menyalin kode. Pahami fungsi setiap bagian dan cobalah menulisnya sendiri.

BAGIAN 02

Persiapan File

Sebelum mulai coding, buat sebuah folder baru untuk menyimpan proyek.

Struktur Folder

personal-profile/ │ ├── index.html │ └── images/ └── profile.jpg

Langkah Persiapan

1. Buat folder proyek

Buat folder bernama personal-profile.

2. Buat file HTML

Buat file baru bernama index.html.

3. Buat folder gambar

Buat folder images untuk menyimpan foto profil.

4. Buka di VS Code

Buka folder proyek menggunakan Visual Studio Code.

Nama file dan folder harus konsisten. Perhatikan juga huruf besar dan kecil pada nama file ketika menggunakan website di server.
BAGIAN 03

Membuat Struktur HTML

Setiap halaman HTML memiliki struktur dasar. Kita mulai dengan membuat kerangka dokumen.

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Personal Profile</title> </head> <body> <!-- Konten website dibuat di sini --> </body> </html>

Penjelasan

  • DOCTYPE mendeklarasikan dokumen HTML5.
  • HTML menjadi elemen utama dokumen.
  • Head berisi metadata dan judul halaman.
  • Body berisi konten yang ditampilkan browser.
Pastikan seluruh elemen halaman nantinya berada di dalam elemen body.
BAGIAN 04

Membuat Konten Website

Kita akan mulai mengisi website dengan beberapa bagian.

A. Header dan Navigation

<header> <h1>MyProfile.</h1> <nav aria-label="Navigasi utama"> <a href="#home">Beranda</a> <a href="#about">Tentang</a> <a href="#skills">Keahlian</a> <a href="#contact">Kontak</a> </nav> </header>

B. Hero Section

Bagian hero menjadi area pengenalan utama. Kita dapat menggunakan heading, paragraf, dan gambar.

<section id="home"> <img src="images/profile.jpg" alt="Foto profil Andi" width="150"> <h2>Halo, Saya Andi</h2> <p>Mahasiswa dan calon Web Developer.</p> </section>

C. About Section

<section id="about"> <h2>Tentang Saya</h2> <p> Saya adalah mahasiswa yang tertarik mempelajari dunia teknologi dan web development. </p> <p> Saya senang belajar, mencoba hal baru, dan membangun proyek digital. </p> </section>

D. Skills Section

Kita menggunakan unordered list untuk menampilkan daftar kemampuan.

<section id="skills"> <h2>Keahlian Saya</h2> <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> <li>Problem Solving</li> </ul> </section>

E. Experience Section

Kita menggunakan tabel untuk menyajikan pengalaman atau kegiatan.

<section id="experience"> <h2>Pengalaman Belajar</h2> <table> <thead> <tr> <th scope="col">Tahun</th> <th scope="col">Kegiatan</th> </tr> </thead> <tbody> <tr> <td>2025</td> <td>Belajar HTML</td> </tr> <tr> <td>2026</td> <td>Membuat Website</td> </tr> </tbody> </table> </section>

F. Contact Section

Kita menggunakan form untuk membuat formulir kontak.

<section id="contact"> <h2>Hubungi Saya</h2> <form> <label for="nama">Nama</label> <input type="text" id="nama" name="nama" required> <label for="email">Email</label> <input type="email" id="email" name="email" required> <label for="pesan">Pesan</label> <textarea id="pesan" name="pesan" required></textarea> <button type="submit">Kirim Pesan</button> </form> </section>

G. Footer

<footer> <p>© 2026 MyProfile. All Rights Reserved.</p> </footer>
BAGIAN 05

Styling dengan CSS

HTML mengatur struktur website, sedangkan CSS digunakan untuk mengatur tampilannya.

Untuk proyek ini, kita menggunakan CSS sederhana di dalam elemen style pada bagian head.

<style> body { font-family: Arial, sans-serif; margin: 0; background: #f8fafc; color: #334155; } header { background: white; padding: 20px; display: flex; justify-content: space-between; align-items: center; } nav a { margin: 0 10px; text-decoration: none; color: #2563eb; } section { background: white; padding: 30px; margin: 20px auto; max-width: 900px; border-radius: 12px; } img { max-width: 100%; border-radius: 50%; } button { background: #2563eb; color: white; padding: 12px 18px; border: none; border-radius: 8px; cursor: pointer; } </style>
Pada tahap ini, fokuslah memahami hubungan HTML dan CSS. Kamu belum perlu menghafal seluruh properti CSS.

BAGIAN 07

Pengujian Website

Setelah selesai membuat website, jangan langsung menganggap proyek sudah selesai. Kita perlu melakukan pengujian sederhana.

Checklist Pengujian

  1. Apakah file HTML berhasil dibuka di browser?
  2. Apakah semua bagian website muncul?
  3. Apakah gambar berhasil ditampilkan?
  4. Apakah tautan navigasi bekerja?
  5. Apakah tabel tampil dengan benar?
  6. Apakah formulir dapat menerima input?
  7. Apakah website tetap nyaman di layar HP?
  8. Apakah terdapat kesalahan pada struktur HTML?
Cobalah membuka website menggunakan ukuran layar yang berbeda, seperti laptop dan smartphone.

FINAL CHALLENGE

Build Your Own Personal Website

Sekarang waktunya membuat website versi masing-masing. Jangan hanya mengikuti contoh Personal Profile Website sebelumnya. Buatlah desain dan konten sendiri.

Ketentuan Proyek

  • Memiliki struktur HTML yang lengkap.
  • Menggunakan minimal 5 elemen semantic.
  • Memiliki header dan navigation.
  • Memiliki minimal 3 section.
  • Menampilkan gambar dengan alt.
  • Memiliki daftar keahlian.
  • Memiliki tabel pengalaman atau kegiatan.
  • Memiliki formulir kontak.
  • Menggunakan CSS untuk styling.
  • Memiliki tampilan responsif.
  • Memastikan seluruh tautan navigasi bekerja.

Ketentuan Tambahan

  • Gunakan identitas dan konten milik sendiri.
  • Gunakan nama class yang mudah dipahami.
  • Susun kode dengan indentasi yang rapi.
  • Jangan hanya menyalin proyek teman.
  • Pastikan dapat menjelaskan kode yang dibuat.
