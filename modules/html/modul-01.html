01. Apa Itu HTML?

HTML merupakan singkatan dari HyperText Markup Language. HTML adalah bahasa markup yang digunakan untuk menyusun struktur dan konten sebuah halaman web.

Sederhananya, HTML memberi tahu browser bagian mana yang merupakan judul, paragraf, gambar, tautan, tabel, dan elemen lainnya.

Analogi Sederhana

Bayangkan kita sedang membangun sebuah rumah:

  • HTML: Struktur rumah seperti dinding, pintu, dan jendela.
  • CSS: Cat, dekorasi, dan desain rumah.
  • JavaScript: Fitur interaktif seperti pintu otomatis.
HTML bukan bahasa pemrograman umum seperti JavaScript atau Python. HTML adalah bahasa markup yang berfungsi menyusun konten.

Apa yang Bisa Dibuat dengan HTML?

  • Website pribadi.
  • Halaman profil.
  • Artikel dan blog.
  • Formulir pendaftaran.
  • Tabel informasi.
  • Halaman portofolio.

02. Perbedaan HTML, CSS, dan JavaScript

Ketiga teknologi ini sering digunakan bersama untuk membangun sebuah website.

Teknologi Fungsi Contoh
HTML Menyusun struktur konten Judul, paragraf, gambar
CSS Mengatur tampilan Warna, ukuran, layout
JavaScript Menambahkan interaksi Tombol, validasi, menu

Contoh HTML

<h1>Halo, Dunia!</h1>
<p>Saya sedang belajar HTML.</p>

Contoh CSS

h1 {
    color: blue;
    font-size: 30px;
}

Contoh JavaScript

alert("Selamat belajar!");
Ingat: HTML menyusun, CSS mempercantik, JavaScript membuat website menjadi interaktif.

03. Apa Itu Browser?

Browser adalah aplikasi yang digunakan untuk membuka dan menampilkan halaman website.

Contoh browser:

  • Google Chrome.
  • Mozilla Firefox.
  • Microsoft Edge.
  • Safari.

Bagaimana Browser Bekerja?

  1. Kita menulis kode HTML.
  2. File disimpan dengan ekstensi .html.
  3. File dibuka menggunakan browser.
  4. Browser membaca dan memproses HTML.
  5. Halaman ditampilkan kepada pengguna.
Browser berbeda dengan search engine. Chrome adalah browser, sedangkan Google Search adalah mesin pencari.

05. Membuat Website Pertama

Sekarang waktunya praktik! Kita akan membuat halaman HTML sederhana.

Langkah 1 — Buat File

Buat folder bernama belajar-html, lalu buat file bernama index.html.

Langkah 2 — Masukkan Kode

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Website Pertamaku</title>
</head>

<body>

    <h1>Halo, Dunia!</h1>

    <p>
        Namaku Biran.
        Aku sedang belajar HTML.
    </p>

</body>
</html>

Langkah 3 — Simpan dan Buka

  1. Simpan file dengan nama index.html.
  2. Buka folder tempat file disimpan.
  3. Klik dua kali file tersebut.
  4. Browser akan menampilkan halaman website.

Mengenal Bagian Kode

Tag / Elemen Fungsi
<!DOCTYPE html> Memberi tahu browser bahwa dokumen menggunakan HTML5.
<html> Elemen akar dokumen HTML.
<head> Berisi informasi tentang dokumen.
<title> Judul halaman pada tab browser.
<body> Berisi konten yang ditampilkan di halaman.
<h1> Heading atau judul utama.
<p> Membuat paragraf.
Eksperimen: Coba ubah tulisan "Halo, Dunia!" menjadi nama kamu. Kemudian ubah isi paragraf dan lihat hasilnya.

07. Coding Challenge

Sekarang buat website profil pribadi sederhana menggunakan HTML.

Instruksi

  1. Buat file bernama profil.html.
  2. Buat judul halaman menggunakan title.
  3. Buat heading berisi nama kamu.
  4. Buat paragraf tentang diri kamu.
  5. Buat daftar hobi menggunakan list.
  6. Buat satu link menuju website favorit.

Tentang Saya:
Saya sedang belajar menjadi
seorang Web Developer.

Hobi:
