HTML LEARNING PATH • MODUL 07

Semantic HTML

Mengenal elemen HTML yang memiliki makna dan fungsi khusus untuk membangun struktur halaman website yang lebih jelas, terorganisir, dan mudah dipahami.

Beginner Level Estimated Time: 60–90 Menit

Pengantar Pembelajaran

Sebelumnya kita telah belajar membuat heading, paragraf, daftar, tabel, formulir, tautan, dan gambar. Sekarang kita akan mempelajari bagaimana menyusun elemen-elemen tersebut menjadi struktur halaman website yang memiliki arti.

Inilah yang disebut Semantic HTML.

Tujuan Pembelajaran

  • Memahami pengertian Semantic HTML.
  • Membedakan elemen semantic dan non-semantic.
  • Mengenal header, nav, main, section, article, aside, dan footer.
  • Menyusun struktur halaman website dengan benar.
  • Menerapkan Semantic HTML dalam proyek sederhana.
Alur belajar: Pahami konsep → Kenali elemen → Perhatikan struktur → Praktikkan sendiri → Kerjakan tantangan.
BAGIAN 01

Apa Itu Semantic HTML?

Semantic HTML adalah penggunaan elemen HTML yang menjelaskan arti atau tujuan dari konten yang ada di dalamnya.

Dengan semantic HTML, browser, mesin pencari, dan teknologi pembaca layar dapat lebih mudah memahami struktur halaman.

A. Perbedaan Semantic dan Non-Semantic

Perhatikan dua contoh berikut.

Contoh 1 — Non-Semantic
<div class="header"> <h1>Website Kubika</h1> </div> <div class="content"> <p>Selamat datang di website kami.</p> </div> <div class="footer"> <p>Copyright Kubika</p> </div>
Contoh 2 — Semantic
<header> <h1>Website Kubika</h1> </header> <main> <p>Selamat datang di website kami.</p> </main> <footer> <p>Copyright Kubika</p> </footer>
Non-Semantic Semantic
div header
div nav
div main
div article
div footer
Perlu diingat: Div bukan elemen yang salah. Div tetap berguna untuk pengelompokan dan kebutuhan styling ketika tidak ada elemen semantic yang lebih tepat.
BAGIAN 02

Header dan Navigation

A. Header

Elemen <header> digunakan untuk menampilkan bagian pengantar atau kepala dari sebuah halaman maupun bagian konten.

Biasanya berisi:

  • Logo website.
  • Judul halaman atau artikel.
  • Informasi pengantar.
<header> <h1>Kubika Developer Team</h1> <p>Learn, Practice, Build</p> </header>

B. Navigation

Elemen <nav> digunakan untuk mengelompokkan tautan navigasi utama.

<nav> <a href="index.html">Beranda</a> <a href="about.html">Tentang</a> <a href="portfolio.html">Portfolio</a> <a href="contact.html">Kontak</a> </nav>
Contoh tampilan:
KUBIKA DEVELOPER TEAM
Beranda Tentang Portfolio Kontak
Gunakan nav untuk kelompok navigasi penting, bukan untuk setiap kumpulan tautan yang ada di halaman.
BAGIAN 03

Main dan Section

A. Main

Elemen <main> berisi konten utama yang menjadi fokus halaman website.

<main> <h1>Selamat Datang di DevLearn</h1> <p>Belajar web development dari dasar.</p> </main>

B. Section

Elemen <section> digunakan untuk mengelompokkan konten yang memiliki tema atau topik yang saling berhubungan.

<section> <h2>Tentang Kubika</h2> <p> Kubika adalah kelompok pengembang web. </p> </section> <section> <h2>Program Pembelajaran</h2> <p> Belajar HTML, CSS, dan JavaScript. </p> </section>
Biasanya section memiliki heading yang menjelaskan topik bagian tersebut. Jangan menggunakan section hanya untuk menggantikan setiap div.
BAGIAN 04

Article dan Aside

A. Article

Elemen <article> digunakan untuk konten mandiri yang dapat dipahami secara terpisah dari bagian halaman lainnya.

Contohnya:

  • Artikel blog.
  • Berita.
  • Postingan komunitas.
  • Ulasan produk.
<article> <h2>Belajar HTML untuk Pemula</h2> <p> HTML adalah bahasa markup untuk membangun struktur halaman website. </p> </article>

B. Aside

Elemen <aside> digunakan untuk konten tambahan yang berkaitan dengan konten utama.

Contohnya:

  • Sidebar.
  • Artikel terkait.
  • Informasi tambahan.
  • Profil penulis.
<aside> <h3>Artikel Terkait</h3> <ul> <li>Belajar CSS</li> <li>Belajar JavaScript</li> </ul> </aside>
BAGIAN 05

Footer

Elemen <footer> digunakan untuk menampilkan informasi penutup dari halaman atau bagian tertentu.

Biasanya berisi:

  • Informasi copyright.
  • Kontak.
  • Informasi pembuat website.
  • Tautan tambahan.
<footer> <p>© 2026 Kubika Developer Team</p> <p>Learn, Practice, Build</p> </footer>
Footer tidak harus selalu berada di bagian paling bawah seluruh halaman. Footer juga dapat digunakan sebagai penutup sebuah article atau section.
BAGIAN 06

Struktur Semantic Website

Sekarang kita gabungkan elemen yang telah dipelajari menjadi satu struktur halaman website.

Ilustrasi struktur website:
HEADER
NAVIGATION
MAIN

SECTION

ARTICLE

ASIDE

Konten tambahan

FOOTER

Contoh Kode Lengkap

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Website Kubika</title> </head> <body> <header> <h1>Kubika Developer Team</h1> <p>Learn, Practice, Build</p> </header> <nav aria-label="Navigasi utama"> <a href="#beranda">Beranda</a> <a href="#tentang">Tentang</a> <a href="#artikel">Artikel</a> </nav> <main id="beranda"> <section id="tentang"> <h2>Tentang Kubika</h2> <p> Kubika adalah kelompok belajar dan pengembangan website. </p> </section> <article id="artikel"> <h2>Belajar HTML</h2> <p> HTML digunakan untuk membuat struktur halaman website. </p> </article> <aside> <h3>Materi Lainnya</h3> <p>Belajar CSS dan JavaScript.</p> </aside> </main> <footer> <p>© 2026 Kubika Developer Team</p> </footer> </body> </html>

Ringkasan Elemen Semantic

ElemenFungsi
headerBagian pengantar atau kepala konten
navKelompok tautan navigasi
mainKonten utama halaman
sectionKelompok konten bertema
articleKonten mandiri
asideKonten tambahan terkait
footerBagian penutup konten
Catatan: Dalam satu halaman biasanya terdapat satu elemen main yang terlihat. Elemen main tidak boleh menjadi anak dari header, footer, nav, article, aside, atau section.
GUIDED PRACTICE

Latihan Terarah

Mari membuat struktur halaman profil sederhana untuk kelompok Kubika.

Studi Kasus: Profil Kubika

Website harus memiliki bagian berikut:

  1. Header berisi nama kelompok.
  2. Navigation berisi tautan halaman.
  3. Main sebagai konten utama.
  4. Section untuk informasi tentang Kubika.
  5. Article untuk menampilkan salah satu artikel.
  6. Aside untuk informasi tambahan.
  7. Footer berisi copyright.

Contoh Kode Latihan

<header> <h1>Kubika Developer Team</h1> </header> <nav> <a href="#home">Home</a> <a href="#about">About</a> </nav> <main id="home"> <section id="about"> <h2>Tentang Kami</h2> <p>Kami belajar dan membangun website.</p> </section> <article> <h2>Kegiatan Kubika</h2> <p>Belajar coding bersama tim.</p> </article> <aside> <p>Informasi tambahan tentang Kubika.</p> </aside> </main> <footer> <p>© 2026 Kubika</p> </footer>
Coba ketik ulang kode di editor masing-masing. Setelah itu, tambahkan CSS sederhana agar halaman memiliki tampilan yang lebih menarik.

CODING CHALLENGE

Mini Project: Kubika Profile Page

Buat sebuah halaman profil kelompok Kubika menggunakan Semantic HTML.

Ketentuan Project

  • Gunakan header untuk identitas kelompok.
  • Gunakan nav untuk navigasi halaman.
  • Gunakan main sebagai konten utama.
  • Gunakan minimal 3 section dengan heading.
  • Gunakan article untuk salah satu konten mandiri.
  • Gunakan aside untuk informasi tambahan.
  • Gunakan footer untuk informasi penutup.
  • Tambahkan CSS sederhana untuk styling.
  • Pastikan struktur HTML tersusun rapi.

Ide Konten Website

  • Profil Kubika.
  • Visi dan misi kelompok.
  • Informasi anggota.
  • Aktivitas belajar.
  • Artikel seputar web development.
