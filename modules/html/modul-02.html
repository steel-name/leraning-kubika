01. Mengenal Struktur HTML

Pada modul sebelumnya kita sudah mencoba membuat halaman HTML sederhana. Sekarang kita akan memahami susunan kode tersebut.

Dokumen HTML memiliki struktur yang terorganisasi. Setiap bagian mempunyai fungsi masing-masing.

Contoh Struktur Dasar

<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <title>Website Pertamaku</title>
</head>

<body>

    <h1>Halo, Dunia!</h1>
    <p>Saya sedang belajar HTML.</p>

</body>
</html>

Bagaimana Susunannya?

  • DOCTYPE memberi tahu browser versi standar HTML yang digunakan.
  • HTML menjadi elemen akar dokumen.
  • Head menyimpan metadata dan informasi dokumen.
  • Body menyimpan konten halaman yang ditampilkan.
Anggap HTML seperti sebuah folder besar. Di dalamnya terdapat bagian head dan body yang memiliki tugas berbeda.

02. Apa Itu DOCTYPE?

DOCTYPE merupakan deklarasi yang ditulis pada bagian paling awal dokumen HTML. 

<!DOCTYPE html>

Fungsinya memberi tahu browser bahwa dokumen tersebut menggunakan standar HTML modern, yaitu HTML5.

DOCTYPE bukan tag HTML biasa. Ia merupakan deklarasi dokumen.

Tips: Biasakan selalu menulis DOCTYPE pada baris pertama setiap file HTML.

03. Mengenal HEAD

Elemen <head> berisi informasi tentang halaman website.

Sebagian besar isinya tidak ditampilkan sebagai konten utama di halaman browser.

Contoh Penggunaan

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Website Pertamaku</title>
</head>

Elemen yang Sering Digunakan

Elemen Fungsi
title Menentukan judul tab browser.
meta charset Menentukan encoding karakter.
meta viewport Membantu tampilan menyesuaikan layar perangkat.
link Menghubungkan file eksternal seperti CSS.
style Menuliskan CSS internal.

Mengenal UTF-8

<meta charset="UTF-8">

UTF-8 merupakan encoding karakter yang mendukung berbagai karakter dan bahasa, termasuk bahasa Indonesia.

Mengenal Viewport

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

Pengaturan ini membantu browser menyesuaikan lebar halaman dengan lebar layar perangkat.

04. Mengenal BODY

Elemen <body> merupakan tempat konten utama halaman website.

Contohnya:

  • Heading atau judul.
  • Paragraf.
  • Gambar.
  • Link.
  • Tabel.
  • Formulir.

Contoh Penggunaan

<body>

    <h1>Selamat Datang</h1>

    <p>
        Ini adalah website pertama saya.
    </p>

    <a href="https://example.com">
        Kunjungi Website
    </a>

</body>
Cara mudah mengingatnya: HEAD berisi informasi dokumen, sedangkan BODY berisi konten halaman.

05. Tag dan Element HTML

Ketika belajar HTML, kamu akan sering menemukan istilah tag dan element. Keduanya saling berhubungan tetapi tidak sepenuhnya sama.

Apa Itu Tag?

Tag adalah penanda yang ditulis menggunakan tanda kurung sudut. 

<p>
</p>

<p> merupakan opening tag, sedangkan </p> merupakan closing tag.

Apa Itu Element?

Element merupakan keseluruhan bagian HTML, yang dapat terdiri dari tag pembuka, isi, dan tag penutup. 

<p>Saya sedang belajar HTML.</p>
Bagian Penjelasan
<p> Opening tag.
Saya sedang belajar HTML. Content atau isi.
</p> Closing tag.
Keseluruhannya Paragraph element.
Ingat: tag merupakan penanda, sedangkan element adalah keseluruhan struktur yang dibentuk oleh tag dan isinya.

06. Mengenal Attributes

Attribute merupakan informasi tambahan yang diberikan pada sebuah elemen HTML.

Contoh:

<a href="https://google.com">
    Buka Google
</a>

Pada contoh tersebut, href merupakan attribute yang menentukan alamat tujuan link.

Contoh Attribute Lainnya

<img src="foto.jpg" alt="Foto profil">

<p class="deskripsi">
    Belajar HTML.
</p>

<input type="text" placeholder="Masukkan nama">
Attribute Fungsi
href Menentukan alamat link.
src Menentukan sumber file.
alt Memberikan deskripsi alternatif gambar.
class Memberikan nama kelas pada elemen.
id Memberikan identitas unik pada elemen dalam dokumen.
type Menentukan jenis input atau elemen tertentu.

07. Mengenal Void Elements

Tidak semua elemen HTML memiliki opening tag dan closing tag.

Ada elemen yang tidak dapat memiliki konten anak, yang dikenal sebagai void elements.

Contoh Void Elements

<br>
<hr>
<img src="foto.jpg" alt="Foto">
<input type="text">
<meta charset="UTF-8">
<link rel="stylesheet" href="style.css">
Element Fungsi
br Membuat baris baru.
hr Membuat pemisah tematik.
img Menampilkan gambar.
input Membuat input pengguna.
meta Memberikan metadata dokumen.
link Menghubungkan resource eksternal.
Dalam HTML5, void elements tidak membutuhkan closing tag. Penulisan seperti <img /> juga dapat ditemukan, tetapi garis miring tersebut tidak diperlukan.

08. Nesting dan Indentation

Apa Itu Nesting?

Nesting adalah kondisi ketika sebuah elemen HTML berada di dalam elemen lainnya. 

<div>
    <h1>Profil Saya</h1>

    <p>
        Saya sedang belajar HTML.
    </p>
</div>

Pada contoh tersebut, heading dan paragraf berada di dalam elemen div.

Apa Itu Indentation?

Indentation adalah jarak atau spasi pada awal baris kode yang digunakan untuk menunjukkan susunan kode.

Contoh kurang rapi:

<div>
<h1>Halo</h1>
<p>Belajar HTML</p>
</div>

Contoh lebih rapi:

<div>
    <h1>Halo</h1>
    <p>Belajar HTML</p>
</div>
Indentation tidak selalu mengubah hasil tampilan HTML, tetapi sangat membantu manusia membaca dan memahami struktur kode.

Perhatikan Penutupan Tag

Contoh yang salah:

<p>
    <strong>Halo!
</p>
</strong>

Contoh yang benar:

<p>
    <strong>Halo!</strong>
</p>

Elemen harus ditutup dalam urutan yang benar, seperti konsep susunan bertingkat.

09. HTML Comments

Comment digunakan untuk memberikan catatan pada kode HTML.

Browser tidak menampilkan comment sebagai konten halaman.

Contoh

<!-- Ini adalah komentar HTML -->

<h1>Halo, Dunia!</h1>

Kegunaan Comments

  • Memberikan penjelasan kode.
  • Menandai bagian tertentu.
  • Membantu developer memahami kode.
  • Memberikan catatan saat bekerja bersama tim.
Perlu diingat: comment tetap bisa dilihat melalui source code halaman. Jangan menyimpan password atau informasi rahasia di dalam comment.

10. Praktik Membuat Kerangka HTML

Sekarang kita akan menggabungkan semua materi yang telah dipelajari.

Langkah 1 — Buat File

Buat file baru dengan nama:

struktur-html.html

Langkah 2 — Masukkan Kode

<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Website Pertamaku</title>
</head>

<body>

    <!-- Bagian utama website -->

    <h1>Selamat Datang!</h1>

    <p>
        Saya sedang belajar struktur HTML.
    </p>

</body>
</html>

Langkah 3 — Jalankan

  1. Simpan file.
  2. Buka menggunakan browser.
  3. Perhatikan judul pada tab browser.
  4. Perhatikan konten yang tampil.
  5. Coba ubah beberapa bagian kode.

Langkah 4 — Eksperimen

  • Ubah title menjadi nama website kamu.
  • Ubah heading menjadi nama kamu.
  • Tambahkan paragraf baru.
  • Tambahkan komentar HTML.
  • Rapikan indentation kode.

12. Coding Challenge

Sekarang saatnya membuktikan bahwa kamu sudah memahami struktur HTML.

Tantangan: Buat Website Profil

Buat sebuah file bernama:

profil-pribadi.html

Ketentuan Pengerjaan

  1. Gunakan DOCTYPE HTML5.
  2. Gunakan html dengan lang="id".
  3. Tambahkan charset UTF-8.
  4. Tambahkan viewport.
  5. Buat title sesuai nama website.
  6. Buat heading nama pribadi.
  7. Buat paragraf perkenalan.
  8. Gunakan minimal satu HTML comment.
  9. Pastikan nesting dan indentation benar.
Aturan: Kerjakan sendiri terlebih dahulu. Jangan hanya menyalin contoh kode. Pastikan kamu dapat menjelaskan fungsi setiap bagian dokumen.
